# Shipyard 0.71.0

Phase 46 refreshes the independent native runtime ladders and confines candidate installations to their selected private profiles.

- Codex uses the Sol and Luna native model ladder; Claude uses its independent Sonnet and Opus ladder. Dispatch validates the selected model and effort and records the actual application receipt.
- Candidate dependency bootstrap, capabilities, defaults, temporary files and package caches remain inside the candidate envelope. Child mutations are checked before the parent continues.
- Native Codex helper files are handled with identity-bound cleanup. Marketplace installation validates Node startup options and refuses an uncomputable dogfood destination.
- Planning, delivery state, development instructions and audit artifacts are excluded from product review and verification. CI skips product checks for process-only changes and retains checks for mixed changes and executable pipeline source.
- Runtime digest trailers remain verifiable through GitHub squash merges.

Publishing this version does not activate a candidate profile. Model/effort pairs without native application evidence remain on HOLD; active profile changes require the existing operator rollout decision.
