# Shipyard 1.0.0-rc.5.4

Patch prerelease based on `v1.0.0-rc.5.3`.

## Fixed

- Gate 2 (`validate-graph.cjs`, also the `plan:post` gate) now applies the delivery host's own verification admission to every PLAN that is not yet merged. A `## Verification commands` bullet that the host would refuse is reported at decomposition time with the plan, the command and the reason, instead of ending an executor at `verification_failed` after the work is done. The same runs on both Claude Code and Codex, because both hosts share one parser and allow-list.
- The shell-operator refusal now names the offending character and says that it applies inside quotes too (`node -e "…;…"`, `\x3c`). Commands remain plain argv; the parser is not relaxed.
- A command with no approved `pipeline.verification_commands` entry is no longer skipped silently. Gate 2 fails and prints the exact JSON entries for a person to add; the planner never writes the allow-list.
- The delivery rules now tell the planner that commands are plain argv without shell operators, that `node -e` with code is not allowed, that only `## Verification commands` bullets run and `<verify>` blocks do not, and that allow-list entries need human approval.
- Before an executor launch the host installs locked dependencies into a worktree that has a lockfile but no `node_modules` (`pnpm install --frozen-lockfile`, `npm ci` or `yarn install --frozen-lockfile`, always with `--ignore-scripts`). A missing package manager or a failed install refuses the launch with the command to run.
- Signed finalization refuses a new path that differs only in letter case from a tracked one (for example `tests/Package/` beside `tests/package/`), on both hosts, before anything is signed.
- `UNKNOWN_TICKET` now says to pass `--graph-dir <project>/.planning/graph` for a ticket that belongs to another repository.

## Validation

Unit cases cover the refusal reasons and ready entries, agreement between the Gate 2 check and `assignPlan`, dependency installation and its refusals, the launch ordering, case collisions and the new hint. The graph-validator smoke drives Gate 2 and the staged `plan:post` gate through fixture projects.
