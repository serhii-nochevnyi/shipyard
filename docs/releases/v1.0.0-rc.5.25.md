# Shipyard 1.0.0-rc.5.25

Patch prerelease based on `v1.0.0-rc.5.24`.

## Fixed

- **Historical repair evidence survives a deleted or moved base branch.** Before a review or CI fix, the Codex host reads the authenticated earlier attempts on the same PR in historical mode. It passes each attempt's own recorded base. The role-artifact reader resolved that base branch name to a live commit before it looked at historical mode, so it failed when the branch no longer existed.
  - After a parent PR was squash-merged and the child moved to the epic, a normal `fetch --prune` removed the parent's remote-tracking branch. The next review-fix then refused before the fixer launched with `base revision could not be determined: … rev-parse --verify origin/<parent branch>^{commit}`, although the recorded base commit still existed and the evidence was intact.
- **A historical read now binds the sealed base identity, not a branch name.**
  - When the recorded base branch no longer resolves, the reader takes the base commit and tree from the authenticated original manifest.
  - It still requires that commit object to exist and to have the recorded tree, and it still checks the recorded base name, the producer head and head tree, the receipt and the artifact digest.
  - A moved branch never changes what a historical read binds.
  - A live read, which can authorize current publication, still resolves the current base branch and refuses when it is missing or stale.

## Validation

A repair-artifact case seals a CI-fix attempt on a base branch.
- After the branch is deleted, the historical read returns the evidence with the sealed base commit, while a live check refuses with `GIT_IDENTITY`.
- After the branch is recreated on another commit, the historical read still binds the sealed commit, while a live check refuses as stale.
- A manifest whose base commit, base tree or base name was changed is refused, and so is a foreign dispatch.
- On rc.5.24 this case fails with the reported `base revision could not be determined`.

Release verification results are recorded in the published prerelease.
