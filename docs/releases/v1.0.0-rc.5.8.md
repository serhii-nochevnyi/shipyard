# Shipyard 1.0.0-rc.5.8

Patch prerelease based on `v1.0.0-rc.5.7`.

## Fixed

- PLAN verification commands run in the OS sandbox by default without per-ticket allowlist approval. Missing or empty `delivery_pipeline.verification_commands` no longer blocks dispatch or skips declared verification.
- Gate 2 and delivery use the same admission rules. Decomposition no longer asks a person to add each new test command to the allowlist.
- Explicit repository entries retain exact-argv host execution and sandbox timeout settings. Changed arguments receive sandbox execution; sandbox failures never fall back to host execution.
- Codex records authenticated verification evidence for automatic sandbox assignments. Failed checks continue to block finalization on both runtimes.
- Quoted inline JavaScript, regular expressions and explicit `bash -c` / `sh -c` commands are accepted without widening host authority. Unquoted shell operators still fail preflight instead of silently becoming arguments to the first program.
- Native Codex executors receive an explicit contract for the PR body, evidence report and structured `ready`/`blocked` completion. Plain text and contradictory results cannot become committed delivery results.
- Both native hosts pin PR and evidence files before signing, then seal them against the authenticated receipt and exact verified commit and tree. Codex returns the artifact references the existing publisher validates; its file pins also survive finalization recovery.
- Missing files, receipt substitution and evidence changes after signing stop publication. Publisher gates remain unchanged. Claude and Codex both reject evidence or HEAD substitution between signing and sealing.

## Upgrade

Refresh the plugin and host components. Existing exact host entries continue to work. New ordinary verification commands need no allowlist entry. Checks that require host access still need an explicitly configured exact host command. Older executor attempts without the structured completion and sealed publication files require a fresh dispatch before publishing.

## Validation

Regression coverage includes Gate 2, live executor preflight, native Codex assignment, Claude repair finalization, sealed evidence, sandbox refusal without host fallback and a real OS sandbox that denies worktree writes. Release verification results are recorded in the published prerelease.
