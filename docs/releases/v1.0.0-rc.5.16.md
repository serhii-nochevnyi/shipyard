# Shipyard 1.0.0-rc.5.16

Patch prerelease based on `v1.0.0-rc.5.15`.

## Changed

- **Codex Sol is now `gpt-6.2-sol`.** OpenAI released GPT-6.2 Sol on 2026-11-17 as the successor to GPT-6.1 Sol, and Codex lists it first in its model catalog. Every Codex role that used `gpt-6.1-sol` now uses `gpt-6.2-sol`, with the same efforts:
  - research, decomposition, integrator, arch-review and code-review keep Sol/high, with Sol/xhigh on the same signals as before;
  - executor, drift-check, ci-fix and review-fix keep Sol/low, with the same escalation rungs.
  - Luna stays `gpt-6-luna`, because there is no 6.2 Luna. The compatibility-only Astra entry stays `gpt-6-astra`. The Claude grid is unchanged.
- **The routed policy is now `adr-014.v9`.** The policy fingerprint covers the version and both role grids, but not the concrete model ids. So the version change is what gives the 6.2 grid its own identity. The new fingerprint is `b9367910886421dd43584516ce09f345afc87ba4d5c4c0830ae294ecdc62205a`.
  - As with earlier versions, only the active version is registered. A record written under `adr-014.v8` is refused at a live gate, and the work must be rerun.
  - The run store now also skips and drops `adr-014.v8` runs on read, as it already did for v6 and v7. Without this, the first v8 record in a store would have stopped every read of that store with `UNSUPPORTED_POLICY_VERSION`.
- **The compatibility Codex palette** is now `gpt-6.2-sol:high@0.169.0, gpt-6.2-sol:xhigh@0.169.0`. `0.169.0` is the Codex CLI version on which `gpt-6.2-sol` was verified. The generator refuses this palette on an older host.
- **Documentation and hook text.** `CLAUDE.md`, the README, the delivery command, the pipeline protocol and the auto-route hook text name `gpt-6.2-sol` and `adr-014.v9`.

## Upgrade note

A delivery run that is in flight with an `adr-014.v8` resolution cannot be continued after the upgrade. Its records are refused as a retired policy, and the work has to be dispatched again under v9. Finish or abandon such runs before installing.

## Validation

Policy cases cover the v9 grid on both runtimes, the new fingerprint, and the refusal of v8, v7 and v6 identities. Run-contract cases cover the v9 palette and the refusal of a v8 record. Run-store cases cover dropping v6, v7 and v8 runs while v9 runs survive, and refusing an unknown future version. The compatibility palette, capability default and README agree on `gpt-6.2-sol` with floor `0.169.0`.

The Codex CLI 0.169.0 accepted `gpt-6.2-sol` at `low`, `high` and `xhigh`. Release verification results are recorded in the published prerelease.
