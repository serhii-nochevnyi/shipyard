# Shipyard 1.0.0-rc.5.7

Patch prerelease based on `v1.0.0-rc.5.6`.

## Fixed

- Native pre-push checks for an existing destination branch compare the exact remote commit supplied by Git with the pushed commit (`remoteOid..localOid`). Already published epic comments no longer block subsequent pushes when `COMMENT_POLICY_BASE` is unset. New forbidden comments still block the push.
- Force pushes compare the two destination/source trees directly. Each ref in a multi-branch push uses its own remote OID. A missing local remote object refuses with fetch guidance instead of falling back to an unrelated integration base.
- The remote-range check retains graph-derived project configuration and ticket identity, including explicit `--graph` and automatic graph discovery. Repository annotation and PHPDoc allowances remain active.
- New destination branches retain PR, explicit, recorded and configured review-base selection.

## Upgrade

Refresh the plugin and host components. Native Git hooks contain an immutable payload: refresh the managed hook in existing checkouts by rerunning its installer, or let managed publication refresh it before the next push. An existing destination branch no longer needs `COMMENT_POLICY_BASE` to avoid rechecking published history. A first push still needs an identifiable review base.

## Validation

The fix passed 37 focused regression cases, including real repeated pushes without a base override, new-comment rejection, force pushes, independent remote OIDs in a multi-ref push, missing-object refusal and graph-scoped PHPDoc allowances. The final independent implementation review is clean. Package, smoke and live release verification are recorded with the published release.
