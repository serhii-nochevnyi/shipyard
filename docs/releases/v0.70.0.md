# Shipyard 0.70.0

These notes cover the Phase 43 integration baseline carried into the Phase 45 epic and the additional Phase 45 work merged on top of it.

## Phase 43 baseline

The integrated tree includes the target-project delivery-at-scale integration from PR #320 and its 0.69.0 version preparation from PR #388. Version 0.69.0 remains the Phase 43 allocation; these notes make no separate publication claim for that work.

## Phase 45 contributions

- Tightened guarded execution and worktree handling: stop-gate arming binds to the resolved path, the doctor distinguishes another checkout, dogfood installs default to a dedicated location, planning-tree writes use owner-bound leases, and both decomposition hosts hold the planning worktree while they operate.
- Improved host coordination and usage attribution: Codex host runs use a lease, handoff successor races are handled, usage reports count Codex host stream tuples, phase-run admission is aggregated, and completed Claude or Codex judgment roles can be recovered from their reservation, native transcript, and artifact digest without relaunch. Codex decomposition also runs detached with separate usage attribution.
- Strengthened context and capture boundaries: the drift gate re-asks when run context is self-contradictory, capture scrubbing replaces Codex account identifiers, scratch capture directories are Git repositories, and fixture scans reject leaked account identifiers.

The Phase 45 changes above are from merged PRs #357, #359–#369, #382, and #383. The candidate includes the first-pass detached-host work related to REQ-193. Full production-caller completion remains queued for Phase 47 and is not claimed here.
