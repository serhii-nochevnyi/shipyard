## Goal

Generate and install a complete, policy-fingerprinted Codex bundle while
applying the operator's Codex-only effort amendment without duplicating or
weakening the canonical ladder.

## Context (Reads)

- `plugins/delivery-pipeline/scripts/codex-dispatch-adapter.cjs`
- `scripts/gen-codex-shipyard.cjs`
- `scripts/install-shipyard-codex.sh`

- `docs/audits/2026-09-08-models-autonomy-probes.cjs`
- `tests/smoke/codex-shipyard-smoke.sh`

## Scope

Replace Codex `Terra/high` with `Terra/xhigh` and every Codex `Sol/medium`
with `Sol/high`: research `Terra/xhigh → Sol/high → Astra/medium`,
decomposition `Sol/high → Astra/medium`, integrator and arch-review
`Sol/high → Astra/medium`, and CI/review fixes
`Luna/max → Sol/high → Astra/medium`. Keep Luna roles, Astra/medium, model
IDs, escalation signals, and Claude's native grid/palette unchanged. Update
the canonical policy, compatibility palette/default, ADR-014 data/table,
capability/config examples, active instructions, and focused tests in the same
ticket so the generated bundle and policy fingerprint cannot disagree.

Remove every executable sentinel/fixer prompt, Agent, session, or in-process
fallback that can launch or record a routed repair without a concrete applied
model-and-effort receipt; preserve only historical non-compliant telemetry.

Generate static variants from policy metadata, record policy and file
fingerprints in the manifest, validate model capability and registration before
replacement, and preserve foreign GSD agent skills. Dynamic roles must not be
represented by misleading static files. Keep installation through the existing
installer only. Keep the dispatch-record agent-file ownership contract aligned
with the generated static role/rung variants so the complete bundle and its
consumer agree on the same Codex palette.
Update the public README, delivery command, sentinel reference, and generator
audit in the same slice so they name only emitted variants, describe
`codex_models` as compatibility input, and exercise the current
capability-aware generator contract.

## Acceptance criteria

- Generated files cover every required static role/rung and never contain a
  model-less or CLI-default variant.
- The installer refuses incomplete, stale, unregistered, or capability-invalid
  bundles before changing the destination.
- The existing Codex smoke proves generation, validation, installation, and
  policy fingerprint consistency.
- Canonical documentation and the audit invoke only emitted agent files and
  describe the ADR-014 policy/capability contract accurately.
- Canonical and compatibility Codex declarations agree on Terra/xhigh and
  Sol/high; Claude's aliases, provider configuration, and role/effort grid are
  unchanged.
