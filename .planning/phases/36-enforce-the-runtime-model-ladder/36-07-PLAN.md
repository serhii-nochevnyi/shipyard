## Goal

Enforce one dispatch boundary for every Shipyard execution, sentinel, drift,
repair, review, architecture-review, and integration launch.

- `plugins/delivery-pipeline/commands/deliver.md`

## Scope

Wire executor=`Luna/max`, PR sentinel=`Luna/medium`, drift-check=`Luna/max`,
integrator and arch-review=`Astra/low` with evidence-based Astra/medium
escalation, and CI/review fixes=`Luna/max` → `Astra/low` → `Astra/medium`. Pass all signals
and prior applied evidence. Reject literal models, omitted efforts, inline
launches, inherited guards/sessions, and phantom records on refusal.

## Acceptance criteria

- Every listed role invokes resolve → validate → launch → receipt.
- Fixed Luna roles remain fixed regardless of global risk/window/checkpoint.
- Repair and judgement escalation is signal-complete and evidence-backed.
- Static Codex roles use generated files; dynamic roles use explicit arguments.
