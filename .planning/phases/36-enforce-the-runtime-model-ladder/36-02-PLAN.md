## Goal

Make the canonical resolver authoritative at the configuration boundary while
preserving ordinary non-routed compatibility behavior.

## Context (Reads)

- `plugins/delivery-pipeline/scripts/model-policy.cjs`
- `plugins/delivery-pipeline/scripts/pipeline-config.cjs`
- `.planning/config.json`
- `.planning/architecture/ADR-014-INTERFACES.md`

## Scope

Expose shared role vocabulary including `decomposition`, resolve the runtime
unambiguously, and reject GSD, `pipeline.models`, effort, per-role, inline, or
session-inherited overrides whenever they conflict with a routed decision.
Keep compatibility readers available only for non-routed callers.

## Acceptance criteria

- All routed consumers delegate model decisions to the canonical resolver.
- Unknown or ambiguous runtime and conflicting override fail closed with the
  source named.
- No compatibility default can become a dispatch fallback.
- Configuration parsing and runtime context expose the policy fingerprint and
  dispatch identity needed by adapters and receipts.
