## Goal

Apply the canonical ladder strictly to Codex launches and remove every silent
model, effort, file, CLI-default, or ordinary-agent fallback.

## Context (Reads)

- `plugins/delivery-pipeline/scripts/model-policy.cjs`
- `plugins/delivery-pipeline/scripts/dispatch-boundary.cjs`
- `plugins/delivery-pipeline/scripts/codex-agent.cjs`
- `plugins/delivery-pipeline/scripts/codex-model-remap.cjs`
- `scripts/gen-codex-shipyard.cjs`

## Scope

Add the Codex adapter mapping Terra=`gpt-5.6-terra`, Sol=`gpt-5.6-sol`,
Luna=`gpt-5.6-luna`, and Astra=`gpt-6-astra` with the ADR-014 efforts. Require
exact static files for static roles and explicit model plus reasoning effort for
dynamic executor/decomposition roles. Refuse stale/missing/conflicting or
unavailable selections with repair guidance.

## Acceptance criteria

- Every Codex role receives an explicit, policy-derived launch selection.
- No path falls back to CLI defaults, an ordinary file, a lower model, or
  parent-session inheritance.
- Static file and manifest identity are checked before launch.
- Adapter receipts report the concrete applied selection rather than copying
  requested values.
