## Test strategy

- The real packet/artifact path records startup bytes and parent-consumed bytes separately; duplicate observations do not double count; missing provider tokens stay unknown.
- A thousand unchanged polls do not become a thousand model turns; waiting-only and context-only runs remain distinct; missing transcript evidence is unknown, not zero.
- Insufficient cohorts or missing attribution produce inconclusive; false-green/skipped-gate/recovery failures force rollback disposition, never promote.
The tracer is an end-to-end local fixture of the real command/host/consumer, not only a helper unit test. Create its test file as the first RED action using the existing harness. New slices use fake time and bounded subprocess fixtures, targeting less than 30 seconds. Record RED command/exit/assertion and GREEN evidence; missing import or syntax error is not valid RED. Negative tests match the intended refusal code/reason and assert that launch, publication, acknowledgment or verdict mutation did not occur; a generic thrown error is insufficient. Call the harness done() and assert at least one registered scenario so a no-op test cannot pass. Run each verification command from repository root.
