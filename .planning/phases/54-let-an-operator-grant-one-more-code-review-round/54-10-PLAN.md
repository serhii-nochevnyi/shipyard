## Scope

1. A local function building the line from a round number and the sealed `{ operator, at, reason }`: `round <N> of <ROUND_CAP>, extended by <operator> at <time>: <reason>` where `<time>` is the first 16 characters of `at` followed by `Z` (for example `2026-11-02T10:45Z`).
2. `status` adds `extension` to its result: the sealed value on the `current` branch, `null` otherwise.
3. `statusDescription`: for a `current` state with a non-null `extension`, append `; ` and the line to the existing text, truncating reason first and operator second so the total is at most `STATUS_MAX`; no extension means the text is unchanged; the limit text is unchanged.
4. `findingsComment`: put the line on its own line directly under the `Code review — round N, scope S` line, inside the header so the existing length loop counts it; absent extension leaves the header unchanged.
