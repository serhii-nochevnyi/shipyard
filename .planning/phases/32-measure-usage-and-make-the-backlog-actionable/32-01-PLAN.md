## Goal
Collect deduplicated usage from explicit transcript files. First isolated slice of ADR-011 wave 0.

## Context (Reads)
ADR-011 D1/D2/D11 and its ROLLOUT/BACKLOG companions; the September 10 usage audit.
Existing scripts are CommonJS, unit tests run through tests/unit, no new dependencies.

## Out of scope
Model/effort changes, live-session restarts, Jira writes, subscription attribution
without evidence, shared dispatch/capacity logic, and phase 30/31 owned commands.

## Scope
Add a pure normalizer and read-only CLI over explicitly supplied Claude/Codex
JSONL files. Rescan full supplied files on each call initially: no unsafe byte-only
cursor, no implicit home scan. Normalize Claude request/message snapshots and
ordinary/advisor iterations, and Codex cumulative token_count observations.
Keep providers, cache categories and missing counters separate. Emit aggregate
JSON and coverage; never prompts, API dollars or claimed quota savings. CLI is
the initial human caller; pipeline-stats integration follows in a later package.

## Acceptance criteria
- Repeated snapshots and repeated input paths do not inflate usage.
- Later partial updates are incorporated; absent output remains unknown.
- Multi-pass Claude usage is not added again to its top-level aggregate; advisor
  passes remain separate and carry their own model.
- Codex cached tokens are a subset of input; reasoning is not added on top of
  output. Cumulative snapshots are not summed as individual requests.
- Reset/decreasing cumulative counters are explicit discontinuities, not negative
  usage. Cross-file session identity prevents resume duplication when available.
- Malformed JSON and unreadable paths produce actionable diagnostics and coverage.
- Unknown provider/schema is rejected or visibly skipped, never zero success.
- Tests use redacted fixtures shaped from local observed records, plus a real CLI
  invocation. A small observed transcript can be processed without exposing text.

## Test strategy
Negative fixtures first, pure unit coverage and real CLI tests. Full test-fast in CI.
