## Goal
Index backlog sources with stable item identities. First isolated slice of ADR-011 wave 0.

## Context (Reads)
ADR-011 D1/D2/D11 and its ROLLOUT/BACKLOG companions; the September 10 usage audit.
Existing scripts are CommonJS, unit tests run through tests/unit, no new dependencies.

## Out of scope
Model/effort changes, live-session restarts, Jira writes, subscription attribution
without evidence, shared dispatch/capacity logic, and phase 30/31 owned commands.

## Scope
Add a pure source inventory/index CLI over explicit project roots, covering local
.planning/backlog notes and GSD 999.x phase sources. Return source-qualified stable
IDs, section identities and content hashes; preserve original notes. Optional
manifest input carries lifecycle and evidence. Unclassified sections stay
untriaged. Changed source hash marks verification stale. Emit bounded searchable
JSON/index output without installing or editing GSD. Cold-start wiring is deferred
to the ownership-safe follow-up after phases 30/31.

## Acceptance criteria
- Every local note and GSD 999.x item appears without source collisions.
- Multi-topic notes expose separate section IDs; repeated headings are distinct.
- Reordering unrelated notes does not rename existing IDs.
- A verified_closed item needs revision and verification evidence; changing the
  source invalidates that verification without deleting history.
- Unknown states, duplicate IDs and malformed manifests are rejected.
- Missing optional source directories are empty; an unreadable declared root is
  an error. Symlink traversal cannot escape the explicit project scope.
- CLI tests prove queries retrieve the relevant note; no output mutates source
  notes, installed GSD, the graph or the tracker. Run against all 39 current notes.

## Test strategy
Negative fixtures first, pure unit coverage and real CLI tests. Full test-fast in CI.

node --test tests/unit/backlog-index.test.cjs
