## Goal
Make requested, applied and observed routing coverage explicit so a treatment
cannot be compared while its dispatch attribution is incomplete. This is the
read-only statistics slice of OPT-03; it does not change launch behavior.

## Context (Reads)
ADR-011 D1, D8 and D11; ADR-011-ROLLOUT Wave 1 / OPT-03; ADR-012 task-level
model ladder; `dispatch-record.cjs`; the existing ladder section in
`pipeline-stats.cjs`; and the 2026-09-10 usage audit.

## Scope
Classify windowed `dispatch` journal rows as requested-policy complete,
applied-effort complete, observed-runtime complete, or incomplete. Count the
missing attribution fields and expose the three eligibility counts in both JSON
and text output. Require a Codex agent file for static Codex roles, while
keeping executor's dynamic path exempt. Preserve unknown and unsupported effort
states as visible evidence; do not turn them into guessed values. Document that
these are comparison-coverage metrics, not quota or savings measurements.

## Out of scope
Workflow or Agent launch changes, automatic dispatch-record writes, model or
effort policy changes, subscription attribution, API pricing, backlog lifecycle
writes, and any global Claude/Codex settings.

## Acceptance criteria
- A row with model, route, task level, runtime and backend is counted as
  requested-policy comparable; a static Codex row without its agent file is not.
- Applied-effort coverage is counted separately and does not copy `effort` into
  `effort_applied`; `unsupported` and `unknown` remain explicit states.
- Observed coverage requires observed model and observed effort, and never
  infers either from requested fields.
- Missing-field counts and eligibility counts agree in JSON and human output,
  including an empty journal and historical rows with no telemetry.
- Existing phase, merge and ladder metrics remain unchanged. The command stays
  read-only and makes no GitHub or filesystem mutations beyond its existing
  reads.

## Test strategy
Extend the subprocess fixtures with complete, partial and Codex-static rows;
assert all three coverage levels and the missing-field behavior. Keep the
existing full unit and smoke suites as the integration check.
