## Goal

Enable the controller only after both runtime adapters, reachability, waits,
and telemetry pass their gates, while preserving rollback and historical truth.

## Scope

Add a versioned rollout flag and capability matrix for Claude and Codex. Wire
the controller-owned run state, receipts, and technical wait categories into
delivery and GSD projection without putting volatile heartbeats into semantic
fingerprints. Add a cross-runtime negative matrix for missing host, stale
agent, wrong runtime, inherited model, wrong scope, stale base, and incomplete
usage evidence. Document rollback and the small set of true human-only gates.

## Out of scope

- Jira issues or export.
- Product-repository changes.
- Changing model ladder thresholds or silently enabling a new provider.
- Automatically merging the protected default branch.

## Acceptance criteria

- The default behavior remains unchanged until a versioned rollout flag and all
  capability checks pass.
- Both runtimes consume the same run contract while keeping separate adapters,
  model ids, provider credentials, and evidence paths.
- Rollback disables new controller launches without deleting run records or
  relabeling historical receipts.
- The semantic GSD projection remains deterministic and excludes volatile
  controller heartbeat/lease fields.
- The cross-runtime smoke reports live success, unavailable capability, and
  refusal separately; no synthetic green satisfies the rollout gate.
- Human checkpoints are limited to protected merge, production rollout,
  credentials/authorization, or unresolved business/security policy decisions.

## Test strategy

Run unit/source-contract tests locally. Run the live cross-runtime smoke in CI
or a proving ground with both runtimes installed; missing credentials produce a
non-green unavailable result and do not enable rollout. Verify rollback with a
temporary state store and a preserved historical receipt.

- `node --test tests/unit/run-rollout.test.cjs tests/unit/source-contract.test.cjs`
- `bash tests/smoke/runtime-control-plane-smoke.sh --capability-only`
