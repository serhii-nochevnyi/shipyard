## Goal

Connect the existing typed Workflow host and Claude adapter to a real,
controller-owned Claude Code launch path with positive application evidence.

## Context (Reads)

- `plugins/delivery-pipeline/scripts/claude-workflow-host.cjs`
- `plugins/delivery-pipeline/scripts/claude-dispatch-adapter.cjs`
- `plugins/delivery-pipeline/workflows/executors.mjs`
- `plugins/delivery-pipeline/workflows/fix-round.mjs`
- `plugins/delivery-pipeline/scripts/dispatch-boundary.cjs`
- `plugins/delivery-pipeline/scripts/run-controller.cjs`
- `tests/unit/claude-workflow-host.test.cjs`

## Scope

Add the host bridge that registers the typed GSD callback, carries a scoped run
context outside serializable workflow args, invokes the supported Claude Code
runtime with explicit native alias and effort, and captures launch/session plus
stream/transcript evidence. Route capability refusal and runtime absence to the
controller's retryable state. Keep the existing Anthropic palette, provider,
and credentials unchanged. Add a live smoke with a capability/credential guard
that reports unavailable rather than fabricating an application receipt.

## Out of scope

- Any Codex launch or model id.
- Changing Claude aliases, provider configuration, or effort policy.
- Removing the hard refusal when the typed binding is absent.
- Making a synthetic AsyncFunction fixture count as live evidence.

## Acceptance criteria

- A real Claude Code launch receives explicit model and effort from the routed
  resolution and the host proves the applied values independently of request
  data.
- Typed GSD launches attest the exact role and `typed-gsd-callback` mechanism.
- Missing host capability, missing recorder, unsupported effort, or absent live
  evidence refuses before a compliant dispatch is recorded.
- The live smoke records the runtime version, launch identity, applied model,
  effort, and run scope, or emits a machine-readable unavailable result.
- Existing synthetic host tests remain useful as unit coverage but are clearly
  separate from the proving-ground smoke.

## Test strategy

Unit-test host and adapter refusal/application paths with injected evidence.
Run the smoke only when Claude Code and required credentials are available;
assert that the unavailable branch is non-green and never a fake receipt.
