## Goal

Make the Codex generated-agent and dynamic launcher a real controller-owned
runtime path with independently observed model and reasoning effort.

## Context (Reads)

- `plugins/delivery-pipeline/scripts/codex-dispatch-adapter.cjs`
- `plugins/delivery-pipeline/scripts/codex-agent.cjs`
- `plugins/delivery-pipeline/scripts/dispatch-boundary.cjs`
- `plugins/delivery-pipeline/scripts/codex-model-remap.cjs`
- `scripts/gen-codex-shipyard.cjs`
- `tests/smoke/codex-shipyard-smoke.sh`
- `plugins/delivery-pipeline/scripts/run-controller.cjs`

## Scope

Add an explicit Codex runtime host for static generated agents and dynamic
typed GSD launches. Bind run scope, process/session identity, immutable agent
handoff, requested model, and reasoning effort to the controller. Capture
applied/observed evidence from the actual Codex process or supported runtime
receipt. Preserve generated-agent source-of-truth and reject stale manifests,
parent-session inheritance, inline fallback, and cross-provider values. Add a
live smoke with an unavailable capability outcome that cannot pass as green.

## Out of scope

- Claude Code or Anthropic model selection.
- Hand-editing generated agent files.
- Changing the ADR-014 Codex model palette or escalation thresholds.
- Using a fake `host.launch` as live-runtime evidence.

## Acceptance criteria

- Static and dynamic Codex paths both carry explicit model and reasoning effort
  through the controller-owned boundary.
- Generated manifest and agent digest are validated before launch and included
  in the receipt.
- The host proves applied model/effort and process identity; a clean exit alone
  is insufficient.
- A stale agent, missing runtime, inherited selection, or cross-provider model
  is refused or marked retryable unavailable without a compliant receipt.
- The smoke distinguishes live success, unavailable capability, and policy
  refusal in machine-readable output.

## Test strategy

Unit-test static manifest, dynamic launch, ownership, and negative inheritance
paths with temporary generated bundles. Execute the proving-ground smoke only
when the installed Codex runtime is available.

## Verification commands

- `node --check plugins/delivery-pipeline/scripts/codex-runtime-host.cjs`
- `node --test tests/unit/codex-runtime-host.test.cjs tests/unit/codex-dispatch-adapter.test.cjs`
- `bash tests/smoke/codex-runtime-smoke.sh --capability-only`
