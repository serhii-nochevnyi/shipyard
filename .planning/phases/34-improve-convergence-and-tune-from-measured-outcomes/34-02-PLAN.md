## Objective

Make adaptive model changes fail closed on runtime evidence while retaining separate Claude and Codex policy palettes and their existing floors.

## Interfaces

`model-capability.cjs` defines a versioned capability snapshot and evaluates model/effort support, launch identity, and completed predecessor evidence. The later launch integration consumes this contract at the boundary without changing either runtime palette.

## Tasks

1. Add capability snapshot validation with supported, unsupported, unknown, and not-required states.
2. Keep the result explicit for the later adapters: supported, unsupported and unknown evidence are distinct, and no policy rewrite is implied.
3. Test runtime-local model-axis detection, capability matching, completed-attempt requirements, bounded fallback input and floor preservation.

## Verification

`node tests/unit/model-capability.test.cjs`

## Done when

The capability contract is ready for the mandatory launch boundary; it cannot authorize an escalated model by itself.
