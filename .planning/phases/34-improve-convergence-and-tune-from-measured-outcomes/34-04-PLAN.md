## Objective

Wire the capability contract into the launch boundary, then coordinate nested and participating agents through owned leases in a declared provider/account scope while keeping degraded and unknown capacity visible.

## Interfaces

`capacity-lease.cjs` owns versioned lease records, atomic acquire/heartbeat/release, expiry recovery, and snapshots. The dispatch boundary reserves before launch; front/state-sync consume the same snapshot for admission reporting.

## Tasks

1. Connect model capability evidence and bounded same-runtime fallback to both host adapters and the mandatory dispatch boundary.
2. Implement durable account-scoped leases with distinct-agent counting, parent-child ownership, expiry, and conservative local fallback on store failure.
3. Wire reservation and release around routed launches, expose coverage/degraded fields in front output and test same-scope sharing, scope isolation, nested launches, duplicate ownership, expiry, unknown scope and store failure.

## Verification

`node tests/unit/capacity-lease.test.cjs && node tests/unit/dispatch-boundary.test.cjs && node tests/unit/front.test.cjs`

## Done when

Capacity can never become unlimited because a scope or durable store is unavailable, and waiting for a child does not consume the last slot.
