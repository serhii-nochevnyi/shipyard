## Goal

D-11 (REQ-169). The legacy `pipeline.gsd_sync` key was dropped with a warning that state-sync buried, and gsd-sync blocked finalization once per phase-01 plan because decompose wrote a ROADMAP declaring only its own phase. `pipeline.gsd_sync` is honoured as a deprecated alias with the warning on the state-sync summary line; decompose writes its phase into ROADMAP in the shape gsd-sync reads; plans of a phase absent from ROADMAP produce one summarised warning instead of a per-plan block. `delivery_pipeline.*` precedence is unchanged.

## Scope

- `pipeline-config.cjs`: when `delivery_pipeline.gsd_sync` is absent and `pipeline.gsd_sync` is a boolean, use it and warn `pipeline.gsd_sync is deprecated — rename it to delivery_pipeline.gsd_sync`. When both are set, `delivery_pipeline.gsd_sync` wins (unchanged) and the legacy key warns as deprecated.
- `gsd-sync-gate.cjs`: apply the same alias rule (read `pipeline.gsd_sync` only when `delivery_pipeline.gsd_sync` is absent), so GSD lifecycle gates and state-sync agree.
- `state-sync.cjs`: print config warnings before `publishGsdProjection()` runs and repeat the deprecation on the final summary line; a gsd-sync block no longer hides them.
- `gsd-sync.cjs` `checkSource`: plans of a phase absent from ROADMAP become one warning per phase (`phase N: <k> plan(s) not declared in ROADMAP.md`), not blockers; other blockers unchanged.
- `adr-bootstrap.cjs`: when ROADMAP exists and lacks `### Phase N:` for the phase being bootstrapped, append the phase block in the same `### Phase N: title` shape; an existing heading is left untouched; other content is never rewritten.
- Tests:
  - `tests/unit/pipeline-config.test.cjs`: legacy-only honoured with a deprecation warning; both set → `delivery_pipeline` wins.
  - `tests/unit/gsd-sync-gate.test.cjs`: legacy `false` passes the gate; `delivery_pipeline.gsd_sync: true` with legacy `false` does not.
  - `tests/unit/gsd-sync.test.cjs`: three plans of an undeclared phase → one warning, no blocker.
  - `tests/unit/adr-bootstrap.test.cjs`: existing ROADMAP without the phase gains exactly one block that `gsd-sync`'s heading regex parses; an existing heading is not duplicated.
- Comment policy on added lines.
