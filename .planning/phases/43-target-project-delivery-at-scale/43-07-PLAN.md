## Goal

D-10 (REQ-168). Concurrency-cancelled `publish` jobs were routed to ci-fix and re-run by hand, and a 15–60 minute `ci-wait.cjs` call exceeded Claude's 600 s Bash cap, so the wait went to the background and was polled with `sleep`. A CANCELLED check superseded by a newer run for the same head and name is ignored; a lone cancelled latest run gets one deterministic, journalled `gh run rerun` that is never green and does not count against `max_attempts`; on Claude one `ci-wait.cjs` call returns within 540 s unless `--timeout` is explicit, with the window budget accumulated across calls in the existing wait record.

Risk is high because green semantics feed the merge gate; the checkpoint verifies on an operator-owned scratch repository that a lone cancel never reads as green.

## Scope

- `check-state.cjs`:
  - `CHECK_FIELDS` adds `link,startedAt,workflow`.
  - `classify`: group rows by check name; a `cancel` row with a newer (`startedAt`) row of the same name on the same head is ignored; a lone latest `cancel` counts in `pending` and in a new `cancelled` tally (with the parsed `run_id`), never in `passing` or `failing`. `isGreen` stays false while `cancelled > 0`.
- `ci-wait.cjs`:
  - For a lone latest cancel whose run id is known and which has not been rerun for this head (per the wait record), run `gh run rerun <run_id>` (argv array, bounded) once and journal `ci_rerun` (`ticket, pr, head, run_id`). A second lone cancel on the same head after the rerun is reported as failing (today's path).
  - On Claude, without an explicit `--timeout`, the call's window is `min(window, 540)` seconds.
  - The wait record stores accumulated waited seconds per head; the park decision uses accumulated seconds against the existing budget, not the window count.
- `log-event.cjs`: register `ci_rerun: ['ticket', 'pr', 'head', 'run_id']`.
- `tests/unit/check-state.test.cjs`: superseded cancel ignored (newer pass → green); lone latest cancel → `pending`, `cancelled: 1`, not green; fail stays failing.
- `tests/unit/ci-wait.test.cjs` (stub `gh`, temp state dir): one rerun on a lone cancel, journalled, second cancel reports failing, no second rerun; with `CLAUDE_CODE_ENTRYPOINT` set and no `--timeout`, the computed window is ≤ 540 s; with `--timeout 900` it is 900; accumulated seconds across three calls reach the park threshold by time.
- `tests/unit/log-event.test.cjs`: `ci_rerun` without `run_id` is refused.
- Comment policy on added lines.
