## Scope

- `deliver-dispatch.cjs` `build research <INV-id>` and `build decomposition <INV-id|ADR-id> --phase <N>`:
  - research builds all four canonical lines in the initial request; source packets bind the investigation inputs and graph to the current source revision;
  - decomposition binds the selected ADR or investigation, its linked ADR when present, requirements, roadmap, available research, phase context, and graph in a structured packet;
  - request builders never select model or effort;
  - the packet contains complete required sources, an explicitly empty unrelated backlog, and digest-verified optional sources. Optional bodies are elided when the full packet exceeds its ceiling; paths and hashes remain, and the prompt directs the role to read only relevant omitted files and verify their hash;
  - Claude research → `claude-investigation-host` resolves each line's model/effort before CLI dispatch; decomposition → `claude-decompose-host.canonicalRequest`;
  - Codex research → `codex-delivery-host.validateArgs`; decomposition → `codex-planning-context-host.requestValue`, which verifies packet sources and the live source revision before delegating to the typed Codex decompose host;
  - an invalid investigation id or missing input file exits 2 naming it.
- `commands/investigate.md` and `commands/decompose.md`: replace the hand-built request steps with the build commands.
- Graph-order correction: T-43-18 depends on T-43-12 because both edit `references/pr-sentinel.md` and T-43-18's guidance consumes the checkpoint vocabulary T-43-12 defines.
