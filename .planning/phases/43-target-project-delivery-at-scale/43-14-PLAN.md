## Scope

- `deliver-dispatch.cjs`: `build <role> <ticket> [--runtime claude|codex] [--pr <n>] [--failure-file <f>] [--review-file <f>]` for roles `arch-review`, `ci-fix`, `review-fix`:
  - inputs from the graph row (branch, plan path, repo, files) and, for fixes, the failure or review evidence file path (passed by path plus digest, never inlined content);
  - only allow-listed signals; never `type`, model or effort;
  - the output is passed through the target host's exported validator before it is printed; a validation error exits 2 naming the field.
  - Codex: arch-review via `codex-delivery-host.requestValue` if its role set accepts it, otherwise refuse with the named reason `codex has no role host for arch-review` (confirm against the released host); ci-fix and review-fix via `codex-delivery-host.requestValue`.
- `commands/deliver.md`: replace the hand-built request steps for these three roles with the `deliver-dispatch.cjs build …` command.
- `tests/unit/deliver-dispatch.test.cjs`: each role × runtime round-trips through the real exported validator (imported, never a hand-written shape); no `type` in signals; a missing failure file exits 2; a named-reason refusal for a role without a Codex path.
- NEW `tests/unit/deliver-builders-contract.test.cjs`: `deliver.md` names the build command for each of the three roles and no longer describes hand-built requests for them; each named script and subcommand resolves.
