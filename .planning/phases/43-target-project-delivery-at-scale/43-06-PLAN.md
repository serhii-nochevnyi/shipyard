## Scope

- NEW `conveyor-scratch.cjs` exports:
  - `SCRATCH_FILES`: the exact file names from `role-artifact.cjs` (moved here; `role-artifact.cjs` imports them and re-exports its existing constant names unchanged).
  - `SCRATCH_DIRS`: `['.shipyard-role-artifacts']`.
  - `isScratch(relPath, {forJudge})`: true for an exact root-level name in `SCRATCH_FILES`; a path under a `SCRATCH_DIRS` entry counts only when `forJudge` is false (finalizer, Codex host, base-merge, gc).   - `statusIgnoringScratch(worktree, {untracked})`: runs `git status --porcelain=v1 -z` (`--untracked-files=all` or `no`) with `maxBuffer` 64 MiB; returns `{ok:true, entries}` without scratch entries, or `{ok:false, code:'STATUS_TOO_LARGE'}` on overflow (a named refusal, never a crash).
