## Goal

The route hook becomes a small program that reads the prompt from stdin, routes
unclear or research-needing work to `/shipyard:investigate` through
`/shipyard:route`, stays silent for `<task-notification>` turns and expanded
slash commands, and injects on unparseable input. The Codex AGENTS.md block uses
the same text source, and `make doctor` checks both (D-05).

## Scope

- New `plugins/delivery-pipeline/scripts/auto-route.cjs` (built-ins and relative requires only), exporting:
  - `claudePolicy()`: the current Claude policy text plus a bullet routing unclear, research-needing or decision-pending work to `/shipyard:investigate` via `/shipyard:route`;
  - `codexBlock(phase)`: the full marker-delimited block, naming `$shipyard-investigate` for both phase 1 and phase 2, with the existing phase-aware large-work route;
  - `shouldInject(raw)`: JSON parse failure or no string `prompt`/`prompt_text` → true; trimmed prompt starting with `<task-notification>` → false; trimmed prompt starting with `/` or containing `<command-name>` or `<command-message>` → false; otherwise true.
  - CLI: reads all stdin, prints `claudePolicy()` when `shouldInject` is true, exits 0 on every path (catch every error and inject). It never echoes prompt content.
- `install-shipyard-claude-hook.sh`: copy `auto-route.cjs` to `$CLAUDE_HOME/hooks/shipyard-auto-route.cjs` (plugin-dir fallback as at `:185-192`); `shipyard-auto-route.sh` becomes a `set -euo pipefail` wrapper that runs `node "<abs>/shipyard-auto-route.cjs" || true`. Keep `ROUTE_HOOK`, `ROUTE_CMD` and the directive-only `# Managed by shipyard:` line. `--remove` also deletes the `.cjs`.
- `install-shipyard-codex.sh`: build the block with `require('<plugin>/scripts/auto-route.cjs').codexBlock(phase)`; keep the marker strings, in-place regex replace and symlink refusal.
- `shipyard-doctor.cjs`: add `claude-route-hook` (the `UserPromptSubmit` entry equals `bash "<CLAUDE_HOME>/hooks/shipyard-auto-route.sh"`, and the installed `.cjs` is byte-identical to the source; otherwise `warn` with remedy `make install-shipyard-claude-hook`) and `codex-route-block` (AGENTS.md block equals `codexBlock(1)` or `codexBlock(2)`; otherwise `warn` with remedy `make install-shipyard-codex`). ## Out of scope

- Changing `route.md` routing, `ROUTE_HOOK`/`ROUTE_CMD` names, or the stop-gate bundle.
- Blocking a prompt under any condition.

## Acceptance criteria

- Plain request and `prompt_text` payloads print the policy; `/shipyard:deliver`, `<command-name>` and `<task-notification>` payloads print nothing; invalid JSON and empty stdin print the policy; exit code is 0 in every case.
- `claudePolicy()` contains `/shipyard:route` and `/shipyard:investigate`; `codexBlock(1)` and `codexBlock(2)` contain both markers and `$shipyard-investigate`.
- After `install-shipyard-claude-hook.sh` into a temp `CLAUDE_HOME`, the installed hook filters fixture payloads the same way, `UserPromptSubmit` is registered with the unchanged command, doctor reports `ok`, and `--remove` deletes both route files.
- Codex smoke: the AGENTS.md block contains `$shipyard-investigate`; the symlink refusal cases stay green.
- README states the route-hook filtering, the new doctor checks, the investigate-only intake with ADR bootstrap, and the deliver-armed stop gate; `bash tests/smoke/docs-smoke.sh` stays green.
