## Goal

A host refusal still exits 1 with its unchanged code and first stderr line, and
now also prints one plain-language hint with a remedy taken from a single
code-to-hint map that the Claude and Codex hosts share (D-02, D-01).

## Scope

- New `plugins/delivery-pipeline/scripts/refusal-hints.cjs` exporting a frozen `HINTS` object `{ CODE: { hint, remedy } }`, `hintFor(code)` (returns a generic default entry for an unknown or missing code, never `undefined`) and `formatHint(code)` returning exactly `hint[<CODE>]: <hint> — remedy: <remedy>` (use `UNKNOWN` when no code is present).
- Map at least: `REFERENCE_UNAVAILABLE` (remedy: `bash scripts/ensure-gsd-core.sh claude` or `make install-shipyard-claude-hook`), `INVALID_INPUT`, `UNSUPPORTED_ROLE`, `SCOPE_MISMATCH`, `INVALID_SIGNAL`, `CONFLICTING_OVERRIDE`, `NONCOMPLIANT_RECEIPT`, `MISSING_RECEIPT`, `INVALID_HOST`, `INVALID_ARTIFACT`, `INVALID_RESULT`, `RUNTIME_UNAVAILABLE`, `STALE_GENERATED_AGENT` (remedy: `make install-shipyard-codex`), `UNSUPPORTED_SELECTION`. Remedies name a reinstall, a fix to the input, or a re-run; none may tell the user to skip, bypass, run the agent directly, switch runtime, or set the stop-gate kill switch.
- In each of the four CLI catch blocks, keep the first stderr line and `process.exitCode = 1` byte-identical, then write `formatHint(error && error.code)` plus a newline as a second stderr line. The investigation host keeps its code-less first line; the code appears only on the hint line.
- In the `claude-decompose-host.cjs` `--capability-only` failure JSON, add a `hint` field holding `formatHint(code)`; keep every existing key and value.
- All four hosts `require('./refusal-hints.cjs')`; no host keeps its own copy of hint text.
- No explanatory code comments (comment policy); rationale goes into test names and assertion messages.

## Out of scope

- `claude-delivery-host.cjs` (owned by T-39-08).

## Acceptance criteria

- `hintFor` returns a non-empty `hint` and `remedy` for every mapped code and a default for `undefined`, `''` and `'NO_SUCH_CODE'`.
- No `hint` or `remedy` string matches `/\b(bypass|skip|directly|other runtime|switch runtime)\b|SHIPYARD_STOP_GATE/i`.
- Spawning `claude-decompose-host.cjs` with an unsupported role exits 1, stderr line 1 still matches `/UNSUPPORTED_ROLE/` exactly as before, and line 2 starts with `hint[UNSUPPORTED_ROLE]: `.
- Spawning `claude-investigation-host.cjs` with bad argv exits 1, its first stderr line is unchanged, and a `hint[` line follows.
- A Codex decompose host refusal exits 1 with the unchanged `codex-decompose-host: ` line followed by a `hint[` line.
- Capability-only failure JSON keeps `status`, `reason`, `detail`, `live_execution` and adds `hint`.
- A source-token assertion shows all four host files contain `require('./refusal-hints.cjs')`.
