## Goal

A child's PR base is chosen for where the squash LANDS, not only for what the
review diff shows. A parent's ticket branch is a legal base only while the
parent's PR is OPEN; once it has merged, the base is the epic. And the invariant
that was violated in silence becomes a check: after any ticket merge, the
ticket's own declared files are asserted reachable from its epic.

## Scope

- **`state[id].base` is resolved against the parent's live state.** While the
  primary parent's PR is OPEN the base is the parent's branch; once the parent is
  `merged` the base is the epic. Resolution is state-sync's because it is the only
  reader with the live parent status, and it must fall to the epic when the parent
  is absent, unreadable or silent — a missing fact must not resolve to a branch.
- `deliver.md`'s publish step states the rule where the base is passed to
  `gh pr create`, and that a base resolved to the epic runs `base-merge.cjs`
  first, so the review diff stays a single slice.
- **The reachability assertion.** After `sentinel.cjs merge` squashes a ticket, it
  asserts the ticket's own `files_modified` are reachable from the epic — the
  ownership matcher already shared with Gate 2 and the scope gate, evaluated
  against the epic tree rather than a diff. A failure is a NAMED alarm on the
  merge result, never a silent success and never a retro-active refusal of a merge
  that has already happened: the squash cannot be undone, so the value is that the
  operator hears about it in the same breath.
- The alarm reaches the journal through the writer that already owns the `merge`
  event, so a run that ends before anyone reads stdout still records it.

- `:488` "once the parent lands, the same child is a merge again"
- `:1331` "once that pre-authorized parent lands, the same child is a merge (the control)"

Both are driven from the shared `cpState()` helper at `:471`, whose child
carries `pr_base: 'ticket/P'`. With `P` merged that IS a limb, so both encode
the PR #52 shape as a pass — the exact mirror of the two fixtures the earlier
attempt corrected in `sentinel.test.cjs`. The remedy is the same four lines:
give `cpState()` a base parameter and have the two merged-parent controls pass
an epic.

There is deliberately NO in-scope alternative. Making the limb rule conditional
on the board knowing the epic would turn both assertions green, and it would be
a hole in a safety gate dressed as a refinement: the gate refuses a limb
regardless of the epic, so the divergence would simply come back.

The lesson for my own planning, stated plainly because it cost two rounds: a
ticket that changes a PREDICATE two readers share must declare every test file
that exercises either reader, not only the ones that name the predicate. The
first amendment reasoned from where the predicate would LIVE; the failure was in
the files that assert what it MEANS.

## Acceptance criteria

- Parent PR open → child's `base` is the parent branch. Parent `merged` → the
  child's `base` is the epic. On base the second case still yields the parent
  branch, so the test fails on current code.
- Parent status absent from state → the base is the epic, and the reason says the
  parent's status could not be read.
- A merge whose declared files ARE reachable from the epic reports normally. The
  PR #52 shape — a squash onto a branch already merged into the epic — reports a
  named alarm naming the unreachable paths, and the alarm is in the journal.
- `deliver.md` contains the literal `base-merge.cjs` in the publish step.
- **The board and the gate agree about a limb base.** With a merged parent whose
  child's `pr_base` still literally names the parent's branch, `dutyItems()` and
  `computeFront()` return the SAME verdict, and `parent-moving.test.cjs`'s
  both-sides case asserts it in one test. On the current branch head the two
  disagree — the gate refuses while `computeFront` reports
  `actionable.merge: ['C']` — so that assertion fails before the fix.
- `limbBaseOf` and `limbRemedy` occur in `parent-moving.cjs` and are imported by
  both `front.cjs` and `sentinel.cjs`; neither reader carries a private copy.
- **Mutation check.** Invert the open/merged test and `sentinel.test.cjs` fails.
  Make the reachability assertion always true and the PR #52 fixture stops
  failing → the fixture is then proving nothing, so it must be built from a real
  git repository, not a hand-written state file.
