## Goal

The dispatch journal T-25-05 exists to make trustworthy gets one writer, a
`--reason` that comes from the thing that made the decision, an `--agent-file`
that is checked against the role it claims, and one sha format.

## Context (Reads)

- ADR-006 D5. Note the correction it records: the orchestrator claimed in a plan
  that `log-event.cjs` refuses `dispatch`, and `OWNED_BY_SCRIPTS` holds four
  events — `merge, status_change, escalation, plan_defect` — not that one. Read
  the constant, not this sentence.
- `.planning/backlog/log-event-does-not-refresh-the-front-but-dispatch-record-does.md`
  — `dispatch-record.cjs mark/clear` calls `refreshFront`; `log-event.cjs` only
  appends. That asymmetry stays; this ticket does not make `log-event` a front
  writer.
- `.planning/backlog/the-dispatch-records-periphery.md`.
- T-25-05's shipped flags on `dispatch-record.cjs mark`: `--model`, `--effort`,
  `--effort-applied`, `--reason`, `--agent-file`, and its rule that absence means
  unmeasured, never `null`.
- `gate-trailer.cjs`'s `normSha`/`shortSha` and its comment that a reader cannot
  lengthen an abbreviation — the reason the journal's format must be the full
  forty.
- `deliver.md:1129` — the `mark` call site.

## Scope

- **`dispatch` joins `OWNED_BY_SCRIPTS`** in `log-event.cjs`, with the same
  `halfAct` message the other four carry: an event whose write is half of an act
  must not be appendable on its own. `dispatch-record.cjs` stays its writer.
- **`--reason` is emitted by the resolver.** `pipeline-config.cjs model <role> --json`
  returns the route it actually took — which rule chose the tier, which chose the
  effort — and `dispatch-record.cjs mark` records THAT, rather than a sentence the
  caller composed about it. A caller-supplied reason is refused, not merged: the
  journal exists to be analysed later, and one field holding two provenances
  cannot be.
- **`--agent-file` is cross-checked against the role.** A `references/ci-fix.md`
  recorded against `arch-review` is a mis-dispatch or a mis-record, and either way
  the journal must not quietly hold it.
- **One sha format: the full forty characters**, on write, for every sha the
  journal records, because `gate_status` records it that way.
- `deliver.md`'s `mark` call site loses the hand-composed reason and gains the
  resolver's `--json` field.

## Out of scope

The dispatch overlay's effect on the front (shipped). Any new event type. The
periphery items the backlog note lists beyond these four. `front.cjs` — its
journal reading is T-27-06's.

## Notes on this ticket's place in the graph

ADR-006's Consequences would have D5 run beside D3/D4 rather than behind them.
It rides the spine instead for one mechanical reason: `pipeline-config.cjs` is
also touched by T-27-08 and `deliver.md` by T-27-04 and T-27-06, and a cascade
gives a child only its PRIMARY parent's work — the diamond-child gap ADR-006
parks explicitly. A single-parent chain is what keeps T-27-08's base complete.

## Acceptance criteria

- `log-event.cjs --event dispatch …` exits non-zero with the `halfAct` message
  and appends nothing. On base it appends successfully, so the test fails on
  current code.
- `dispatch-record.cjs mark` still writes the `dispatch` event and still refreshes
  the front — the refusal is about the append-only path, not about the owner.
- `mark --reason "<anything>"` is refused with a message naming the resolver as
  the source. `mark` without it records the resolver's route verbatim.
- `mark --agent-file references/ci-fix.md --role arch-review` is refused and names
  both.
- Every sha the journal writes is 40 characters; an abbreviated input is refused
  rather than padded or accepted.
- **Mutation check.** Remove `dispatch` from `OWNED_BY_SCRIPTS` and
  `log-event.test.cjs` fails. Make the agent-file check compare against itself and
  `dispatch-record.test.cjs` fails.

## Test strategy

TDD in `log-event.test.cjs` for the refusal (it is one constant and one message,
and it is the item this repository asserted wrongly once — so the test is the
record). `pipeline-config.test.cjs` for the resolver's route field, resolved in a
config-free temp cwd. `dispatch-record.test.cjs` for the cross-check and the sha
format, over a temp graph dir.
