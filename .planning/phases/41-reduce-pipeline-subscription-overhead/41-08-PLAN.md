## Goal

Two push-path point fixes, moved from phase 40 (formerly T-40-02, D-14/D-28) at the user's request on 2026-09-25 after both defects blocked this phase's own planning push:

- a. `delivery-state.yaml` written by `state-sync.cjs` has no comment header and is byte-identical for identical state. Two syncs of the same GitHub state produce the same file, and the comment-policy gate no longer blocks a push that regenerates state.
- b. The Claude pre-push hook gates the repository that git resolves for the push target, not a directory guessed from command text.

Observed on this branch: `cd <worktree>; git push …` was refused with `publish-gate: not a git worktree: <worktree>;` (the `cd` capture keeps the `;`), and `git -C "$W" push` was refused with `not a git worktree: <session cwd>/$W` (no expansion). A regenerated `# snapshot generation N — observed …` line then failed comment policy and had to be removed by hand, as in `17a80aab`.

## Scope

- `state-sync.cjs` (a): drop both comment lines from the YAML output. Sort keys deterministically wherever the YAML is built from object iteration, and emit no timestamp, generation or other run-varying value in the YAML body. Keep `delivery-state-meta.json` and the stdout generation line unchanged.
- NEW `tests/unit/state-sync-yaml.test.cjs`: drive the YAML writer through its exported function or the CLI against a fixture graph in `os.tmpdir()` with a stubbed `gh` on `PATH` (the pattern in `tests/smoke/sentinel-smoke.sh`).
- Backlog entry: mark it resolved in the file's existing status convention, naming REQ-157a.
- `scripts/shipyard-pre-push-gate.sh` (b): collect candidate directories from `git -C <path>` and `cd <path>` (quoted or bare, with trailing shell separators stripped, resolved against `payload.cwd` when relative), then the payload `cwd`. Run `git -C <candidate> rev-parse --show-toplevel` on the first candidate the command names. If the command names a target and git cannot resolve it (contains `$`, does not exist, not a worktree), refuse with exit 2 and a message naming `git -C <absolute worktree> push`. Only when the command names no target is `payload.cwd` resolved through git. Invoke `publish-gate.cjs` with the git toplevel.
- NEW `tests/unit/pre-push-gate.test.cjs`: spawn the hook with JSON payloads against two hermetic repositories in `os.tmpdir()` (own `GIT_CONFIG_GLOBAL`, `commit.gpgsign=false`) and a stub `publish-gate.cjs` (via `SHIPYARD_PUBLISH_GATE`) that records the worktree it was given.
- Comment policy on added lines.
