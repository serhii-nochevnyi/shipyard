## Goal

REQ-156 makes usage and overhead reports comparable per verified completion while retaining all consumption and uncertainty, including recovery work.

## Context (Reads)

- P41-F in `CONTEXT.md`; `41-RESEARCH.md:275-282` defines attribution and readiness inputs.
- `plugins/delivery-pipeline/scripts/usage-attribution.cjs:14-53` already records dispatch/run/ticket/model/effort identities; `usage-report.cjs:145-215,293-329,600-671` deduplicates provider messages but leaves verified completion null. `optimization-report.cjs:9-17` warns against nested token double counting.
- `orchestration-overhead.cjs:12-35,405-454` already has treatment readiness, 20 completions, 95% attribution, seven-day quality gate and inconclusive verdict; extend this report rather than creating a ledger.
- T-41-01 supplies the judgment launch observation contract. Existing delivery-state/receipt and controller history are read-only outcome and parent/child inputs; T-41-02 and T-41-04 later prove their producer behavior in final integration.

## Scope

- Join parent continuation and child dispatch usage only by authenticated repository/project, owner run and dispatch/ticket relationship, supported transcript ID and a verified delivery outcome. Use delivery-state plus trusted receipt/integration evidence as the outcome producer; transcript stop is never completion. Parent and child remain separate usage rows before rollup. Unmatched or ambiguous attribution stays unknown.
- Deduplicate replayed and streamed provider messages by provider identity before summing. Input, cache read, cache creation and output are disjoint reported categories; iteration/thinking/reasoning fields remain explanatory subsets, never additive totals. Include failed, interrupted, parked, recovery and revalidation rows in cohort consumption.
- Emit processed input, cache categories, output, model turns, retries, wait polls, total cohort consumption, and median/p90 per verified completion. Match runtime, model, effort, role scope and account scope, with one treatment difference at a time. Record false greens, skipped gates, lost constraints, duplicate work, reopens and escaped defects alongside existing rollback keys.
- Preserve existing 20 verified completions, 95% attribution, output coverage, seven-day defect window and quality gates. Return inconclusive when insufficient evidence, not a manufactured savings value. Separate implemented, installed, behaviorally verified and efficiency-measured state in report output.

## Out of scope

Provider billing conversion, a second usage ledger, stream parser fixture migration owned by phase 40, or model rung changes.
