## Goal

Phase-41 integration (outcome `needs-fix`, 2026-09-26) found one blocking cross-ticket defect. T-41-01's `firstResponseUsage` in `claude-role-host.cjs` takes the first streamed assistant record. It does no message-id max-merge, needs no stop marker and applies no `<synthetic>` filter, so it can label partial counters as `observed`. `usage-report.cjs` (T-41-06) already parses the same Claude transcripts correctly. This ticket makes the first-response measurement use the same semantics.

## Context (Reads)

- `plugins/delivery-pipeline/scripts/claude-role-host.cjs` `firstResponseUsage` (digest-bound transcript read, session filter, `USAGE_FIELDS`).
- `plugins/delivery-pipeline/scripts/usage-report.cjs` Claude branch: `row.type === 'assistant'`, `msg.model !== '<synthetic>'`, key `['message', msg.id]` with `['uuid', row.uuid]` fallback, `mergeUsage` = per-field `Math.max`, `complete ||= Boolean(msg.stop_reason)`.
- Phase 41 `INTEGRATION.md` finding for REQ-151.

## Scope

- In `firstResponseUsage`, collect the session's assistant records in transcript order. Skip `<synthetic>` models and records without a stable message id (uuid fallback). Group records by that key and take the first key in order. Max-merge its `USAGE_FIELDS` across all of that key's records, and report `observed` only if one of them carries `stop_reason`. Otherwise report `unknown` with a named reason: incomplete, synthetic-only, no identity, or conflicting model.
- Keep the digest, byte and session identity checks unchanged. Do not import `usage-report.cjs` internals: `mergeUsage` is not exported, and the role host must stay self-contained. Match its semantics and pin them with fixtures.
- Fixtures in `tests/unit/claude-role-host.test.cjs`: streamed partial-then-final records of one message id (max-merged, observed), a record without `stop_reason` (unknown), a `<synthetic>` first record followed by a real one (real one measured), a record without an id (skipped), and an unchanged digest-mismatch refusal.

## Out of scope

Changing `usage-report.cjs`, a shared transcript parser module, or phase-40 provenance work.
