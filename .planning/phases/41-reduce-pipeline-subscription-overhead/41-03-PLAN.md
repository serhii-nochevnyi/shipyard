REQ-153 is a regression and installation gate over merged T-39-03. The six historical false replies become owner-scoped fixtures, with shell polls counted separately from model turns.

## Scope

- Create one hermetic fixture that invokes the current arming, stop and waker interfaces for the six historical false-wake shapes, foreign worktree board, unchanged wait, changed owning CI/review/dependency state and duplicate wake claim.
- Assert zero model-turn requests for foreign/unchanged states and exactly one for the relevant owner transition. Count shell polls separately. Assert the hook resolves the armed scope and caller installation path as recorded evidence; release/operator checks compare actual installed file digests and settings path after installation.
- If a fixture demonstrates a residual source defect, record the exact failing scenario and create a scoped follow-up ownership amendment before source modification; this plan does not claim a passing fixture proves installed behavior.

## Out of scope
