## Goal

Make the active model ladder resolve the exact current model IDs in each native
runtime while preserving role tiers, effort levels, provider boundaries, and
historical receipt meaning.

## Context (Reads)

- `.planning/architecture/ADR-014-mandatory-runtime-model-ladder.md`
- `.planning/architecture/ADR-014-INTERFACES.md`
- `plugins/delivery-pipeline/scripts/runtime-adapters.cjs`
- `plugins/delivery-pipeline/scripts/model-policy-internal.cjs`
- `plugins/delivery-pipeline/scripts/pipeline-config.cjs`
- `scripts/gen-codex-shipyard.cjs`

## Scope

Update the Codex policy IDs to `gpt-6-luna` and `gpt-6-sol`, and pin Claude
Opus launches to `claude-opus-5-5` while retaining the logical `opus` rung.
Keep Sonnet and Fable on their current Anthropic aliases. Preserve Luna/max as
the Codex executor base, every existing effort and promotion signal, and the
independent provider grids. Update the policy fingerprint and generated Codex
selections from their canonical source. Raise the compatibility palette's
minimum Codex CLI version to the lowest version verified with the new IDs.
Refuse stale or unsupported runtime selections before launch. Keep historical
receipts and usage records unchanged.

## Out of scope

- Changing effort values, role ownership, or escalation thresholds.
- Cross-provider model or credential fallback.
- Rewriting historical usage and dispatch observations.

## Acceptance criteria

- The canonical resolver returns the new runtime model ID for each active
  Luna, Sol, and Opus rung, with the existing role/effort decisions intact.
- Generated Codex agent selections and capability metadata agree with the
  canonical GPT-6 IDs; stale variants refuse before launch.
- The canonical Opus rung resolves to `claude-opus-5-5`; runtime application
  evidence is proven separately by T-38-02.
- Old receipts retain the exact model and policy fingerprint they recorded.

## Test strategy

Cover every role/rung model mapping, effort, promotion signal, generated Codex
selection, stale capability rejection, and immutable historical receipts.

- `node scripts/gen-codex-shipyard.cjs --check`
