## Goal

Accept Claude application evidence only from the assistant transcript records
written by the child session that the host launched.

## Context (Reads)

- `plugins/delivery-pipeline/scripts/claude-runtime-host.cjs`
- `plugins/delivery-pipeline/scripts/claude-dispatch-adapter.cjs`
- `tests/unit/claude-runtime-host.test.cjs`
- `tests/smoke/claude-runtime-smoke.sh`

## Scope

Read the persisted Claude transcript for the host-generated `session_id` and
consider only `type: "assistant"` records whose `sessionId` equals that ID.
Take the model from the assistant message and effort from that same assistant
record. Ignore attachments, foreign sessions, and stdout fields that the CLI
does not emit. Wait a bounded interval for transcript flush and refuse missing,
ambiguous, or contradictory evidence. Keep the pinned Opus ID
`claude-opus-5-5` exact.

Launch with explicit edit and Bash permission for the scoped worktree, prompts
disabled, and no blanket permission bypass. Keep the capability-only probe free
of model calls. Add an explicitly opted-in live smoke that performs one small
file edit and one Bash command in a scratch worktree and records a real runtime
receipt or machine-readable `unavailable`/`refused` status.

## Out of scope

- Codex runtime selection or authentication.
- Cross-provider fallback.
- Treating synthetic stream output as live evidence.

## Acceptance criteria

- Only matching assistant transcript records establish applied model and effort.
- An attachment with another model, another session's effort, or stdout-only
  values cannot satisfy or contradict the launched session's selection.
- Missing transcript evidence refuses before a compliant receipt is recorded.
- The Claude Opus launch and receipt retain `claude-opus-5-5` exactly.
- The ordinary smoke makes no model call; the opt-in smoke proves scoped edit
  and Bash access and never fabricates success.

## Test strategy

Use a recorded-shape fixture with assistant, attachment, and foreign-session
records. Test exact-session selection, transcript flush timeout, contradictory
evidence, explicit permission arguments, and fail-closed behavior. Run the live
smoke only in the disposable proving ground.

## Verification commands

- `node --test tests/unit/claude-runtime-host.test.cjs tests/unit/claude-dispatch-adapter.test.cjs`
- `bash tests/smoke/claude-runtime-smoke.sh --capability-only`
- `bash tests/smoke/claude-runtime-smoke.sh --live --worktree <scratch-worktree>`
