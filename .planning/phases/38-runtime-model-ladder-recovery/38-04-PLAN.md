## Goal

Make the Codex host a real delivery caller for dynamic executors and generated
static agents, with model and reasoning effort proven by the launched process.

## Context (Reads)

- `plugins/delivery-pipeline/scripts/codex-runtime-host.cjs`
- `plugins/delivery-pipeline/scripts/codex-dispatch-adapter.cjs`
- `plugins/delivery-pipeline/scripts/codex-agent.cjs`
- `scripts/gen-codex-shipyard.cjs`
- `tests/smoke/codex-runtime-smoke.sh`

## Scope

Add `codex-delivery-host.cjs` to construct the scoped runtime host, register
the durable recorder/controller, and call both `launchAgent()` for generated
static roles and the typed dynamic executor path through the mandatory dispatch
boundary. Pass the resolved GPT-6 model and effort explicitly, preserve
workspace-write sandboxing, and refuse inherited selection, stale generated
agents, or cross-provider data. Add an explicitly opted-in smoke that edits a
scratch worktree and runs Bash, then validates native Codex session evidence.

## Out of scope

- Anthropic runtime or credentials.
- Changing the Luna/max base or Sol promotion signals.
- Blanket sandbox or approval bypasses.

## Acceptance criteria

- Both static and dynamic delivery calls reach a production Codex launcher.
- Every launch carries the resolver-selected native model and reasoning effort
  and records the actual session/process identity.
- The active IDs are `gpt-6-luna` and `gpt-6-sol`; ordinary executor work stays
  on Luna/max, and promotion requires its existing approved signal.
- Stale agent digest, inherited selection, missing runtime, or contradictory
  evidence refuses before a compliant receipt is recorded.
- The live smoke proves edit and Bash access in its scratch worktree and emits
  `passed`, `unavailable`, or `refused` without a synthetic green result.

## Test strategy

Test generated static manifest identity, dynamic and static entrypoints,
resolved model/effort, process evidence, stale-agent refusal, and scoped work
permissions. Run the allowance-consuming live smoke only by explicit opt-in.

## Verification commands

- `node --test tests/unit/codex-delivery-host.test.cjs tests/unit/codex-agent.test.cjs tests/unit/codex-runtime-host.test.cjs`
- `bash tests/smoke/codex-runtime-smoke.sh --capability-only`
- `bash tests/smoke/codex-runtime-smoke.sh --live --worktree <scratch-worktree>`
