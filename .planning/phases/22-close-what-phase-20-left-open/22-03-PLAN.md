## Goal

`drift-record.cjs` and `log-event.cjs` still swallow a following flag as
`--graph`'s value. Three sibling scripts gained that guard during phase 20,
independently, because a reviewer found the same bug in each; these two were
simply not on a guarded PR.

## Context (Reads)

- Occurrences of a `startsWith('--')` check on a flag's value, counted on the
  merged epic:

      escalation-record.cjs   2      failure-signature.cjs   3
      attempt-history.cjs     1      drift-record.cjs        0
                                     log-event.cjs           0

- `escalation-record.cjs` — the reference implementation. Read how it validates
  and what it says when the value is missing or flag-shaped; these two must
  match it, not invent a third phrasing.
- CLAUDE.md on `drift-record.cjs` / `log-event.cjs`: they take `--graph` in ANY
  position, "one spelling, shared with `log-event.cjs`", and must refuse when the
  resolved graph dir has no `tickets.json`. One spelling has to mean one parser;
  it currently means three.
- The consequence is not cosmetic: a `--graph` that silently resolves to the cwd
  is how a drift verdict was once written into a worktree where state-sync never
  reads it, with exit 0. The refusal exists to make that loud.
- CLAUDE.md, the `-1` trap: "Watch the `-1` case when stripping a flag by index:
  `i !== flagAt + 1` with no flag present reads as `i !== 0` and eats the
  subcommand." Both files strip by index. Pin it.
- Reuse check (§5): three copies of this parser already exist. Prefer extracting
  one shared helper over adding a fourth and fifth copy — but if extraction
  would widen `files_modified` beyond this ticket, keep the copies IDENTICAL and
  say so in the PR body, because the next ticket to touch them must know.

## Scope

- Both scripts reject a `--graph` whose value is absent or begins with `--`,
  with the same wording as the reference implementation.
- Both keep accepting `--graph` in any position, before or after positionals.
- The `-1` no-flag case is pinned by test in both.

## Out of scope

The `tickets.json` refusal (both already have it), any other flag, and the three
scripts that already carry the guard.

## Acceptance criteria

- `drift-record.cjs mark T-01 plan.md reason --graph --json` fails naming the
  flag-shaped value, rather than treating `--json` as a directory.
- `--graph` with no following token fails the same way.
- `--graph <dir>` in any position still resolves, and with no `--graph` at all
  the subcommand is not consumed.
- `log-event.cjs` behaves identically for all four cases.

## Test strategy

Assert on behaviour (exit code + which store was written), not on the message
text — a script that fails for the wrong reason must not pass.
