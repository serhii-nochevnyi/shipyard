## Goal

`escalation-record.cjs mark T-01-01 ""` is accepted today: a non-empty argument
array holding nothing a human can read. The older, more-used path gets the guard
its sibling already has.

## Context (Reads)

- **Why this is stacked on T-22-01 rather than parallel to it:** both tickets
  edit `escalation-record.cjs`, which is a file conflict Gate 2 rejects outright.
  A dependency is the honest resolution — T-22-01 restructures how that file
  produces human-facing text, and this guard extraction lands on top of it.
  Extending either ticket's `files_modified` to paper over the overlap would
  void the no-conflict guarantee for both.

- The divergence, both in the same file on the merged epic:

      line 229 (mark)              if (!reason.length)
      line 272 (mark-plan-defect)  if (!reason.join(' ').trim().length)

- The comment at line 268-271 already argues the case: "Checked on the JOINED,
  TRIMMED string, not the argument count — `mark-plan-defect T plan ""` has a
  non-empty positional array but nothing a human could read. Found by Copilot's
  review of this PR." The reasoning was written; only one call site received it.
- `escalation-record.cjs` is "the durable park, and the sole writer of the
  journal's `escalation` event" (CLAUDE.md). The reason string is the ENTIRE
  inheritance of the next session — an empty one is the defect the script exists
  to prevent, which is what its own failure text says.
- Reuse check (§5): the two guards should become one helper rather than two
  copies of a condition — the copy is exactly how they diverged.

## Scope

- One validation helper used by both `mark` and `mark-plan-defect`.
- Each keeps its own failure TEXT (they address different readers: unblocking a
  PR versus deciding how to re-plan) — only the test changes.
- Whitespace-only, empty-string and zero-argument cases all fail the same way.

## Out of scope

Every other guard in the file, and `drift-record.cjs` (its reason handling is
not part of this ticket's evidence).

## Acceptance criteria

- `mark T-01 ""` exits non-zero with the existing reason-required message.
- `mark T-01 "   "` behaves identically.
- `mark T-01 real reason here` still succeeds and stores the joined string.
- `mark-plan-defect` keeps its current behaviour exactly.

## Test strategy

refactor cannot re-diverge them silently.
