<objective>Record the routing-signal rule of ADR-033 R-7 where the model ladder is documented, and pin it so the grid and threshold cannot drift under it.</objective>

## Goal

ADR-033 R-7 (D-07): "the `inputTokens > 250000` signal counts the size of the work (diff plus required material), not the launch prompt, so a route that keeps the prompt small does not lower the model rung; the rule is recorded as a note on ADR-014 and the grid is unchanged." ADR-033 lists ADR-014 as related. Research `constraints.md` TC-6: the Claude host measures `inputTokens` as `ceil(promptBytes/4)` of the whole inline prompt (`claude-role-host.cjs:908-911`), so a design that moves the diff out of the prompt and keeps measuring the prompt silently lowers the rung.

## Context (Reads)

- `.planning/architecture/ADR-014-mandatory-runtime-model-ladder.md` headings (`## Decision`, `### 2. Approved Codex role ladder`, `### 3. Approved Claude Code role ladder`, `## Scope fences`) and lines near `:62-64,93-100,112` that describe measured input above the threshold.
- `plugins/delivery-pipeline/scripts/model-policy-internal.cjs:40,306` (`WINDOW_THRESHOLD_TOKENS`, read only) and `plugins/delivery-pipeline/scripts/model-policy.cjs` (`POLICY_HASH`, read only).
- `.planning/architecture/ADR-033-review-input-routing.md` R-7 and Consequences.
- Duplicate check: ADR-014 has no statement about what `inputTokens` measures for the review roles.

## Scope

Add one subsection to ADR-014 under its decision section titled "Note (ADR-033 R-7): routing signal for review roles", stating the rule, that it applies to the integrator and architecture-review roles on both runtimes, that other roles keep their existing measurement, that the rung table and `WINDOW_THRESHOLD_TOKENS` are unchanged, and linking ADR-033. The test reads the ADR text and the two constants.

## Out of scope

Any code change that implements the rule (T-53-20, T-53-23, T-53-25); changing a rung, signal or the policy hash; editing ADR-033.

## Acceptance criteria

- ADR-014 contains the note heading, the words "work" and "launch prompt", the reference to ADR-033 R-7 and the sentence that the grid is unchanged.
- The test asserts `WINDOW_THRESHOLD_TOKENS` is still 250000 and that the ADR-014 table rows for integrator and arch-review contain the same rung text as before the note (compared against the rows read from the file excluding the note).
- ADR-014's existing structure still parses with the repository's ADR checker (`node plugins/delivery-pipeline/scripts/adr-ingest.cjs --input .planning/architecture/ADR-014-mandatory-runtime-model-ladder.md --check`).
