## Scope

New `child-output.cjs` exporting `sanitizeChildOutput(text, { max, home })` and `streamTerminalReason(rawStdout)`. Sanitizing removes ANSI CSI and OSC sequences and C0 and C1 control characters (newlines and tabs become single spaces), replaces occurrences of the home directory with `~`, redacts `Authorization: Bearer|Basic` values, well-known token shapes (`sk-`, `ghp_`, `gho_`, `ghs_`, `xox[abp]-` followed by at least 16 token characters) and `NAME=value` or `NAME: value` pairs whose NAME ends in KEY, TOKEN, SECRET or PASSWORD, and bounds the result to `max` characters (default 1024) by keeping the first and last halves with an explicit marker `[... N characters omitted ...]`. `streamTerminalReason` scans the stream-json lines for the last object carrying a `terminal_reason` string and returns it only if it matches `^[a-z0-9_.-]{1,64}$`, else null. The runtime host's non-zero-exit failure becomes one line: `Claude process exited N`, then ` (terminal_reason: X)` when present, then `: <excerpt>` when stderr is non-empty; `details.stderr` keeps the sanitized text bounded at 4096 and `details.terminal_reason` is added.

## Acceptance criteria

- Child output with ANSI colours, a `Bearer` token, `ANTHROPIC_API_KEY=...`, the home directory and 1 MiB of text yields a one-line excerpt of at most 1024 characters with none of those substrings and an omission marker.
- A fake child that exits 1 with stderr text and a stream whose last record has `terminal_reason` `prompt_too_long` produces an error whose message contains `Claude process exited 1`, the terminal reason and the stderr excerpt, and contains no newline; `error.details.stderr` is at most 4096 characters and sanitized.
- A child that exits 0 and the other failure branches behave as before.
- The new failing-child case passes an explicit scratch `HOME`, `CLAUDE_CONFIG_DIR`, session-transcript root and GSD agent root (all under its own `os.tmpdir()` directory) and asserts the recorded launch environment names them, so the launcher resolves nothing under the operator's home (`claude-runtime-host.cjs:366,374,418` read `HOME` and the Claude home); the sanitizer cases pass an explicit `home` and never read the real one.
