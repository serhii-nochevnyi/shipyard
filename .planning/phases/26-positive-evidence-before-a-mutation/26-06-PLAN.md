## Goal

`merge-codex-config.cjs` recognises an existing `[agents]` table by TOML
grammar (trailing comments, whitespace, quoted keys), never appends a
duplicate table, writes atomically, and re-parses the result before replacing
the user's `~/.codex/config.toml`.

## Context (Reads)

- ADR-004 D6 (audit F21, reproduced: input `[agents] # my limits` → two
  `[agents]` declarations, exit 0; a TOML parser rejects the duplicate and
  Codex refuses to start).
- `scripts/merge-codex-config.cjs` ~85–95: `BARE_AGENTS` regex matches only a
  bare `[agents]` line; `hasBareAgents` false → `lines.push('', '[agents]',
  'max_depth = 1')`. Header detection by regex over raw lines is the defect
  class; the GSD marker handling (~95) has the same shape.
- The file must stay dependency-free (installer path, no node_modules): a
  small TOML header/line tokenizer is in scope, a full parser is not — but the
  re-parse step may shell out to `python3 -c 'import tomllib'` when available
  and skip with a note when not (state which it did).
- `make test-codex-shipyard` exercises the installer end to end with network;
  the new unit test must not need it.

## Scope

- Header detection: strip a trailing `#` comment outside quotes, trim, accept
  `[agents]`, `[ agents ]`, and treat `[agents.x]` sub-tables as evidence the
  parent may be implicit (TOML allows it) — never append a bare `[agents]`
  when any `[agents…]` header exists.
- Atomic write (`tmp` + `rename`), and a post-write parse check when `python3`
  with `tomllib` is on PATH (exit non-zero and restore the original on failure).
- Fixtures: commented header, spaced header, only sub-tables present, already
  merged (idempotent), empty file, no file.

## Out of scope

Generating the agents themselves (T-25-02).

## Acceptance criteria

- `[agents] # my limits` input → exactly one `[agents]` header in the output;
  today two — the test fails on current code.
- Running the merge twice yields byte-identical output.
- An input the merge would corrupt (forced via a fixture) leaves the original
  file untouched and exits non-zero.

## Test strategy

Unit tests over temp files; TDD on the commented-header case first.
