## Goal

`executors.mjs` and `drift-gate.mjs` throw on malformed `args` (with the parse
error), return `[]` only for an explicitly empty list, and fail the run when a
dispatched ticket comes back without a result — so an adapter failure can no
longer look like a legitimately empty wave.

## Context (Reads)

- ADR-004 D9 (audit F25, reproduced: `args = '{invalid'` → `[]`, no agent, no
  error).
- `executors.mjs` ~62–70: `typeof args === 'string' ? (() => { try { return
  JSON.parse(args) } catch { return {} } })() : (args || {})`; then
  `argv.tickets || []`. The 2026-07-28 note explains WHY the string form is
  tolerated (the runtime hands `args` over as JSON text) — keep the tolerance,
  drop the swallow. `drift-gate.mjs` has the same block.
- `fix-round.mjs`'s copy is T-24-06's (in flight) — not here.
- These files cannot be `node --check`ed or imported (top-level `return`);
  `tests/smoke/overlay-image-smoke.sh` ~44–54 shows the wrap the runtime uses.
  The unit test evaluates the source through that wrap with `agent`/`parallel`
  stubs.

## Scope

- Shared shape in both files: parse failure → `throw new Error('workflow args:
  not valid JSON — ' + e.message)`; `args` not an object or `tickets` not an
  array → throw naming the field; `tickets: []` → `[]`.
- After the fan-out: every input id must appear exactly once in the results;
  otherwise throw listing the missing ids (an agent that crashed is a failed
  run, not a shorter list — drift-gate already maps a crash to `drifted`; keep
  that and add the completeness check).

## Out of scope

`fix-round.mjs` (T-24-06). Prompt contents.

## Acceptance criteria

- Wrapped `executors.mjs` with `args='{invalid'` throws (today returns `[]` —
  fails on current code); with `{tickets: []}` returns `[]`; with a stubbed
  `agent` that omits one ticket's result, throws naming that id.
- Same three for `drift-gate.mjs`.
- `make test-overlay`'s wrap-check still passes syntactically (`bash -n` of the
  smoke, and the wrap piped to `node --check` in the verification commands).
