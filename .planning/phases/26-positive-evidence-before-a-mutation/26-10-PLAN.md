## Goal

A ticket is `left_behind` when its OWN phase has landed (epic merged into the
base) without it — never because a higher-numbered phase landed first. The
front's ordering, the stop gate's all-left-behind hatch and the waiter's
exclusion all read the same flag.

## Context (Reads)

- ADR-004 D10 (audit F26). `front.cjs` ~352–360: `newestLandedPhase = max phase
  of any merged ticket; leftBehind(id) = phase(id) < newestLandedPhase`. This
  repository delivered phase 22 before 21 on purpose (ROADMAP §22); under this
  rule every phase-21 ticket was `left_behind` while it was the live work, and
  the stop gate's "everything actionable is left behind" hatch could allow a
  stop over it. `.planning/backlog/phase-22-followups.md` recorded the concern.
- `stop-gate.cjs` and `ci-wait.cjs` read `left_behind` from the front (grep
  `left_behind`); `state-sync.cjs` computes `epicInfo[…].landed` (T-26-03 made
  it tri-state) — the evidence this ticket needs is already on the board.
- Chain: T-26-05 → T-26-03 → T-24-11 own `state-sync.cjs`/`front.cjs` before
  this; `stop-gate.cjs` is T-24-09's (landed), `ci-wait.cjs` T-24-10's.

## Scope

- `state-sync.cjs` passes `epics` (with `landed`) into `computeFront`;
  `front.cjs`: `leftBehind(id) = epics[phase(id)].landed === true &&
  state[id].status !== 'merged'`. No phase-number comparison remains.
- `stop-gate.cjs`/`ci-wait.cjs`: unchanged logic, but their tests gain the
  out-of-order case.

## Out of scope

Explicit abandonment marks (a future store); the ordering keys other than
`left_behind`.

## Acceptance criteria

- Fixture: phase 22 fully merged and landed, phase 21 tickets open → phase 21 is
  NOT left behind (today it is — fails on current code); the stop gate blocks
  on an actionable phase-21 front.
- Fixture: phase 20's epic landed with one ticket still `pr-open` → that ticket
  IS left behind.
- No `newestLandedPhase` symbol remains in `front.cjs`.

## Test strategy

TDD in `front.test.cjs` with two-phase fixtures; stop-gate/ci-wait tests read
the fronts the new front produces.
