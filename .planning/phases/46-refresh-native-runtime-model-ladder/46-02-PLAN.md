## Goal

Codex dispatch requests and generated static roles carry the new exact selection, and native evidence must match it before a receipt is compliant.

## Context (Reads)

- `plugins/delivery-pipeline/scripts/codex-agent.cjs:75-210` selects static files or explicit dynamic arguments from canonical policy; `tests/unit/codex-agent.test.cjs:56-95,177-267` has old tuple, remap and capability cases.
- `plugins/delivery-pipeline/scripts/codex-dispatch-adapter.cjs:218-385,395-480` checks availability, static digest and requested/applied/observed evidence; `tests/unit/codex-dispatch-adapter.test.cjs:110-273,499-568` covers these boundaries and repair progression.
- `scripts/gen-codex-shipyard.cjs:293-390` generates TOML and a manifest from canonical variants; `tests/unit/gen-codex-shipyard.test.cjs:142-185,260-290,617-665` already checks palette, manifest and stale validation.
- T-46-01 owns the policy and palette; do not reimplement or edit its files here. No generator logic change is indicated by the inspected source: it iterates `policy` variants and embeds `POLICY_VERSION`/`POLICY_HASH`.

## Scope

P46-A/C/E: update only the named regressions to use the new contract, including all static generated rungs, dynamic executor/decomposition launch arguments, exact Sol 6.1 identity and effort, Luna/medium sentinel, verified repair chain, stale manifest, unsupported capability and mismatched observed model/effort. If a test exposes a generator or adapter defect, stop and re-scope with an explicit owner instead of making an undeclared production edit.

## Out of scope

Editing the canonical policy, installed runtime, package mirror, global Codex configuration, phase-45 host files or historical captures.

## Acceptance criteria

- `codex-agent` returns explicit `{model: 'gpt-6.1-sol', reasoning_effort: 'low'}` for ordinary execution and Sol/high for critical/checkpoint, with research/decomposition/judgment high/xhigh and fixed sentinel Luna/medium.
- The generator test checks each static TOML model/effort and the new version/hash/digest in its staged manifest. Stale old-policy files and a changed digest refuse.
- Adapter tests show a host downgrade, effort mismatch, missing native evidence and unsupported exact pair cannot become compliant receipts; a valid exact-session pair can. Both fixer chains require their boundary-verified immediately preceding tuple.

## Test strategy

Under the enabled TDD mode, update expected assertions first and observe old-grid failures on the T-46-01 dependency branch if any stale fixture remains. Use the existing host fakes and generator temporary output directory; they do not call a real Codex account. The native live entitlement check belongs to T-46-06.
