## Scope

P46-C/D/E: update the smoke's pinned Claude palette assertion, exact new manifest/agent checks and negative cases; assert package mirror bytes, package-build identity and install provenance. Regenerate `plugins/shipyard/` only after T-46-01/02/03/04 source is present. Add a v6-history fixture in the test without editing durable receipts or captured files. Write `ADR-024-ROLLOUT.md` with isolated Codex/Claude home setup, provenance inventory, live proof gate and rollback boundaries; all live checks are deferred to T-46-06's operator checkpoint.

## Out of scope

Installing into a shared active home, changing installed global settings or active controllers, rewriting historic receipt/control bytes, D6 outer coordination, and duplicate quota experiment machinery.

## Acceptance criteria

- `plugins/shipyard/` is regenerated by `node scripts/package-shipyard-codex.cjs` from the reviewed source; its policy/runtime-adapter and guidance mirrors match source bytes, and its `.codex-plugin/plugin.json` version plus `package-build.json` digest change with the new content.
- The marketplace test checks new identity and mirror equality even on ticket/epic branches; a deliberately stale package fails that assertion. The isolated smoke installs to a temporary home, validates new manifest version/hash and each digest, and refuses stale/altered agent or mismatched observed selection.
- A fixed old `adr-014.v6` attribution record remains classified `stale` and noncompliant under the new policy. No existing history file or sealed INV-011 report is modified.
- The runbook names the prior reviewed package as rollback target, records package/source/provenance and exact native receipt fields, preserves in-flight old-policy runs, and leaves actual activation with the operator and ADR-023 D6 owner.

## Test strategy

Use the existing Node test and Bash smoke. Update their assertions before regenerating the package so old-grid projections fail. Rebuild once from the completed source, then run both narrow checks. The smoke's synthetic capability pairs prove installer wiring only; they never count as account entitlement or live application evidence.
