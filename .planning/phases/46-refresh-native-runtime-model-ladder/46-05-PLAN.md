## Acceptance criteria

- `plugins/shipyard/` is regenerated by `node scripts/package-shipyard-codex.cjs` from the reviewed source; its policy/runtime-adapter and guidance mirrors match source bytes, and its `.codex-plugin/plugin.json` version plus `package-build.json` digest change with the new content.
- The marketplace test checks new identity and mirror equality even on ticket/epic branches; a deliberately stale package fails that assertion. - A fixed old `adr-014.v6` attribution record remains classified `stale` and noncompliant under the new policy. No existing history file or sealed INV-011 report is modified.
- The runbook names the prior reviewed package as rollback target, records package/source/provenance and exact native receipt fields, preserves in-flight old-policy runs, and leaves actual activation with the operator and ADR-023 D6 owner.
- The coordinator prelaunch log proves both T-46-01 and T-46-04 merge commits are ancestors of the effective package base and their outputs exist there. Missing ancestry or merely branched parents block package execution.

The smoke's synthetic capability pairs prove installer wiring only; they never count as account entitlement or live application evidence.
