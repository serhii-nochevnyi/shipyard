## Goal

R16, doctor half (D-03). A dogfood install from another session currently turns this session's doctor red. The Claude cache check reports `error` "cache matches no release" (`scripts/shipyard-doctor.cjs:136-162`), and the Codex digest mismatch is `error` even for a dogfood record (`:164-197`). `:396` then sets exit 1, so `tests/live/live-round.sh:139-141` fails its `preconditions` stage and the release is refused. After this ticket, the provenance record carries an owner identity, and the doctor reports a dogfood cache owned by another checkout as `foreign`, a warn-level status that does not set the exit code. A release cache whose files differ stays `error`.

## Scope

1. `host-provenance.cjs`: keep an optional `source_root` in `freeze` (a realpath string; anything else is dropped). The writer records `source_root` = the realpath of the checkout toplevel, and `readRecord` preserves it. Records without it stay valid.
2. `shipyard-doctor.cjs`: add status `foreign`. A dogfood record whose `source_root` differs from the realpath of the doctor's own repository root is reported as `foreign`, naming both roots, the sha and the dirty flag. For such a cache, the file-digest mismatch against a release is suppressed, because it is not a release. The summary prints `foreign` rows, and they never set `process.exitCode`. A dogfood record without `source_root` keeps today's behaviour. Own dogfood stays `warn`. A release (non-dogfood) cache that matches no tag stays `error`.
3. `tests/smoke/claude-hook-smoke.sh`: add `cache_doctor` fixtures for a foreign dogfood cache (expects `foreign` and exit 0) and for this checkout's own dogfood cache (expects `warn`).

- A dogfood cache written from another checkout makes the doctor print `foreign` and exit 0. The same cache before this change printed `error` and exited 1 (RED).
