## Goal

P1 wiring (D-05). Each decompose host acquires the planning writer lease (T-45-07) for `{realpath(worktree), phase directory}` before it launches a researcher, planner or checker. It heartbeats the lease with its run, re-asserts the fence immediately before sealing, and releases the lease afterwards. A second session planning the same tree is refused before any model launch. A seal attempted after a takeover is refused, and so is a seal over a phase-directory file that a non-owner changed. The lease is **host-internal**: no request field is added, so T-43-15's request builders keep round-tripping.

This ticket depends on T-45-07 (it imports the module) and on T-45-04 (it edits `codex-decompose-host.cjs` after the clock/heartbeat injection, and reuses that injected clock for the lease). This diamond is intended: the child needs both parents' code.

## Scope

1. **Claude.** `runDecomposition` creates the lease under `<privateStore(scope)>/writer` (injectable as `dependencies.writerLease`). It acquires with `owner = {run_id, owner_id}` and `base_revision = git -C worktree rev-parse HEAD`, before the definition is written and before any launch. The lease heartbeats on the same tick as the controller. `assertFence` and `changedSince` run immediately before `decompositionEnvelope`, and `release` runs in `finally`.
2. **Codex.** `runCli` does the same with a store beside `defaultRunStoreDir(scope)`, using the injected `now`/`heartbeat` from T-45-04. `assertFence` and `changedSince` run immediately before `sealResearchArtifact` / `sealPlans` (`:279-280`).
3. **Foreign edits.** A changed phase-directory path that is not among the paths the owner's own result declares refuses the seal with `FOREIGN_EDIT`. The refusal names the path, the lease owner and the epoch, so no receipt or envelope is sealed over a foreign edit.
4. **Refusals are pre-launch where possible.** `WRITER_LEASED` is raised before `resolveDispatch` is consumed and before any model launch. Its hint names `recover` (via `formatHint`, `claude-decompose-host.cjs` imports `refusal-hints.cjs`).

## Acceptance criteria

- **Two sessions, same worktree and phase.** The second host refuses with `WRITER_LEASED` and launches no runtime; the test's runtime stub records zero calls.
- **Different phases or worktrees** run concurrently.
- **Takeover.** A host whose lease is taken over before sealing refuses with `WRITER_FENCED`, and seals nothing (no sealed index file exists).
- **Foreign edit.** A non-owner file changed mid-run refuses with `FOREIGN_EDIT`, naming the path.
- **Release.** The lease is released on success and on failure, so a following run acquires immediately.
- **Contract.** `canonicalRequest` still refuses unknown fields, and the existing host tests pass unchanged.
