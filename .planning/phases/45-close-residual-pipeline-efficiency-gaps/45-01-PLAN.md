## Goal

S1 (D-02, ADR-023). Today an armed session lets the newest `delivery-front.json` among `[cwd, ...worktreesOf(cwd)]` decide (`plugins/delivery-pipeline/scripts/stop-gate.cjs:515-531`, `candidates.sort` at `:530`). A sibling session's newer board can then answer for this session: it can trap an idle session or silence a live one ([backlog](../../backlog/stop-gate-selects-foreign-session-board.md)). This ticket binds the marker to the realpath of one board chosen at arm time. While the marker is bound, the hook reads only that board. An unbound (legacy) marker keeps today's scan but is bounded, and `stop-gate-arm.cjs disarm` removes the session's own marker. The fix is proven on the source and on the installed copied hook bundle. It is a correctness fix, and no quota claim is made.

## Scope

1. **Marker v2 (additive).** `arm(cwd, sessionId, { graphDir })` resolves the board as `--graph-dir <d>`, then `SHIPYARD_GRAPH_DIR`, then `<cwd>/.planning/graph` if it holds `delivery-front.json` or `tickets.json`. It writes `{ session_id, armed_at, cwd, board }` with `board = fs.realpathSync(dir)`, and only when the realpath ends in `/.planning/graph`. With no resolvable board it writes the marker without `board` (unbound). The CLI prints whether the marker is bound and, if so, to which board.
2. **Hook, bound marker.** `stop-gate.cjs` reads the marker body (a new exported `readMarker` in `stop-gate-arm.cjs`). When `board` is present, re-`realpath` it and require the `/.planning/graph` suffix. It then reads only `<board>/delivery-front.json` and sets `graphDir = board`, so the ledger and every hatch follow it. A missing, unreadable, non-directory, suffix-less or realpath-changed board leads to `allow()` plus one stderr line that names `stop-gate-arm.cjs arm --graph-dir <board>` and `disarm`. It never falls back to another board, and it never traps.
3. **Hook, legacy/unbound marker (bounded).** Keep the candidate scan, so `:749` still blocks. Bound it in two ways: (a) at most one refusal per turn, ignoring ledger round-advancement for unbound markers (the old `stop_hook_active` rule); (b) no refusal once `armed_at` is older than `RESYNC_MS`. Each refusal names the remedy. The old hook reads v2 markers through `isArmed`, which checks only `session_id`, so the skew in both directions is safe.
4. **`disarm`.** `stop-gate-arm.cjs disarm [--session-id <id>]` validates the id with the same regex. It unlinks `markerPath(cwd, id)` only when the body's `session_id` equals the id, and exits 0 when the marker is absent. It exits non-zero on an I/O error or when the body belongs to someone else. Export `disarm`. Re-arming overwrites the session's own marker, which is how a session rebinds.
5. **Installed bundle test.** Add a new `tests/unit/stop-gate-installed.test.cjs`. It runs `bash scripts/install-shipyard-claude-hook.sh` with `CLAUDE_HOME=<tmp>` and `SHIPYARD_GSD_AUTO_INSTALL=0`, then runs the installed `<tmp>/hooks/shipyard-stop-gate/stop-gate.cjs` against the two-armed-session fixture. It also asserts that the installed files are byte-identical to the source.
6. Rewrite the `stop-gate.cjs:89-91` header note as a one-line `@invariant:`. Add no other new comments.

## Acceptance criteria

- **Two armed sibling sessions.** Session A is bound to board A (live, older `generated_at`) and session B to board B (fixpoint, newer). A's hook blocks from board A, and B's hook allows from board B. Swapping which board is newer does not change either decision.
- **Stale main cwd.** A session whose cwd is a stale main checkout, bound to a live phase-worktree board, blocks from the phase board.
- **Bound to a missing, changed, symlink-swapped or suffix-less board.** The hook allows with the remedy line and never reads another board.
- **Legacy unbound marker.** The `:402`, `:426` and `:749` cases keep their verdicts. They are renamed as legacy tests, each gets a bound counterpart, and none is deleted. An unbound marker refuses at most once per turn and never after `RESYNC_MS`.
- **`disarm`.** It removes only the caller's own marker. It refuses (non-zero, marker kept) a marker whose body names another session or is malformed, and it is idempotent when the marker is absent. After `disarm`, the hook allows.
- **Installed copy.** The installed copied hook gives the same two-session verdicts as the source, and its files are byte-identical to the source.
- **Hook contract.** Every hook run still exits 0 (`tests/unit/stop-gate.test.cjs:89` pattern). The bundle still requires only built-ins or relative files.
- **Human checkpoint (blocking).** The operator reinstalls the real hook outside the sandbox (`bash scripts/install-shipyard-claude-hook.sh`). The operator then compares `shasum -a 256 ~/.claude/hooks/shipyard-stop-gate/stop-gate.cjs` with the source, runs `node scripts/shipyard-doctor.cjs`, and confirms the legacy bound (research A1) before activation.
