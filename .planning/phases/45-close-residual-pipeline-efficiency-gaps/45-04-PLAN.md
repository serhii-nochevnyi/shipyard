## Goal

R9, decompose-host part (intake N5). The test "production <role> reaches its native child and records session evidence" (`tests/unit/codex-decompose-host.test.cjs:326`) runs with a 2000 ms wall-clock lease and a 20 ms heartbeat (`:369-370`), and a fake child that closes after `setTimeout(170)`. `runCli` builds its run controller without `now` (`plugins/delivery-pipeline/scripts/codex-decompose-host.cjs:330-333`), although `createRunController` accepts `options.now`/`options.clock` (`plugins/delivery-pipeline/scripts/run-controller.cjs:260`). Its heartbeat is a real `setInterval` (`codex-decompose-host.cjs:356-363`). On a loaded CI runner, the synchronous parsing and sealing block the heartbeat for longer than the TTL, which produces `LEASE_EXPIRED 'the run lease has expired'` (`run-controller.cjs:297-298`). After this ticket, the lease clock and the heartbeat trigger are injectable, the test controls both, and the refusal the lease exists for still fires.

## Scope

1. **Wave 0 reproduction (RED evidence).** Before changing code, run the suite 50 times in a loop, with a CPU-burning sibling process to simulate a loaded runner. Record the failing assertion text in the commit message. If it does not reproduce, a test that drives the heartbeat-blocking case directly (sealing takes longer than the TTL on the injected clock) is the RED case.
2. `runCli` options gain `now` (passed to `createRunController` as `now`) and `heartbeat` (a scheduler `{ start(fn, ms) → stop }`, defaulting to `setInterval`/`clearInterval` with `unref`). Production behaviour is unchanged when they are omitted.
3. The test drives a manual clock and a manual heartbeat. It ticks the heartbeat explicitly before asserting `heartbeat_at > acquired_at`, and never depends on wall-clock time.
4. Add a guard-removal case: advancing the injected clock past the TTL with no heartbeat must still refuse with `LEASE_EXPIRED`.
