## Goal

P2, Claude (D-05). This is the Claude counterpart of T-45-09. A completed Claude judgment role (researcher, planner or checker) whose host timed out or died before `record` is recovered into its original receipt, for its original `dispatch_id`, without a second launch. Recovery uses the durable reservation (`recorder.getReservation`, from T-45-09), the transcripts the host already saved under `<privateStore>/transcripts`, and the host-private launch snapshot. All of it goes through the same Claude verification functions a live launch uses. Anything missing, incomplete, altered or still live refuses, and no receipt is synthesized.

This ticket depends on T-45-09, which adds `getReservation` and fixes the refusal vocabulary and the `launch.json` shape. The dependency on T-45-08 (the `claude-decompose-host.cjs` lease wiring) is transitive through T-45-09.

## Scope

1. **`claude-runtime-host.cjs`.** Export `verifyCompletedClaudeLaunch({ session_id, start_evidence_file, transcript_path, model, effort, gsd_role, worktree })`, composed from the existing `readSessionStartEvidence` → `readSessionEvidence` → `parseAssistantTranscript` checks. Live launch behaviour is unchanged.
2. **`claude-decompose-host.cjs` live path.**
   - Persist `launch.json` (`{dispatch_id, run_id, session_id once known, lease_epoch, tree_snapshot}`, 0600) under `privateStore(scope)` before the launch.
   - Include `dispatch_id` and `run_id` in the thrown refusal on failure, so that recovery can name them.
3. **`claude-decompose-host.cjs recover --dispatch <id>`** (a CLI entry beside `main`, plus an exported `recoverDecomposition`).
   - Acquire the writer lease.
   - Require the reservation to exist and not be recorded.
   - Run `verifyCompletedClaudeLaunch` on the saved transcripts.
   - Take the result only from the transcript's final assistant result.
   - Require `changedSince(tree_snapshot)` to equal the paths the result declares.
   - Re-run the receipt compliance checks of `:227-240` unchanged, seal via `decompositionEnvelope`, and `record` under the original `dispatch_id`.
   - It never calls the runtime launcher.
4. **Refusal codes are identical to T-45-09.** Unknown-live applies when the recorded Claude child pid is alive.

## Acceptance criteria

- **Recovery per role.** For each of `gsd-phase-researcher`, `gsd-planner` and `gsd-plan-checker`, a completed saved transcript recovers to one verified receipt with the original `dispatch_id`, and the injected launcher records zero calls.
- **Refusals.** Each of the following refuses with its code and records nothing: no reservation; already recorded; transcript missing; transcript without a complete model-and-effort record (`claude-runtime-host.cjs:325`); a model or effort mismatch; tree changed outside the declared paths; live pid.
- **Crash boundary.** A kill after reservation and completion but before `record` recovers. A kill before completion refuses.
- **Live path.** Live-path tests pass unchanged.
- **Human checkpoint.** An operator compares one recovered receipt with a live receipt, field by field, before merge.
