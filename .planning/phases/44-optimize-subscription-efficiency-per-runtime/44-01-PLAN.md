## Goal

P44-A, D-A1, D-A3, D-A4, D-A6 and D-X1 (REQ-176, REQ-178, REQ-179, REQ-181, REQ-184). The hosts already save quota records, but no code reads them. Claude saves `rate_limit_event`, where `utilization` is a fraction from 0 to 1. Codex saves `event_msg/token_count` `payload.rate_limits`, where `used_percent` is already a percent. This ticket adds a pure, total module, `subscription-observation.cjs`. It turns those records into one allow-listed envelope, `shipyard.subscription-observation.v1`, and summarizes the envelopes into per-series values, `shipyard.subscription-usage.v1`, that never sum across series. It is the contract that T-44-02, T-44-03, T-44-04 and T-44-06 consume. No runtime host is changed, no process is started and no call is made.

## Scope

- NEW `plugins/delivery-pipeline/scripts/subscription-observation.cjs`. It requires only `node:` built-ins, and its exports are frozen:
  - `ENVELOPE_SCHEMA = 'shipyard.subscription-observation.v1'` and `SUMMARY_SCHEMA = 'shipyard.subscription-usage.v1'`.
  - `SOURCES`, a frozen table keyed by source:
    - `claude-stream`: `{ provider: 'anthropic', runtime: 'claude', unit: 'fraction' }`.
    - `codex-native`: `{ provider: 'openai', runtime: 'codex', unit: 'percent' }`.
    - `claude-statusline`: `{ provider: 'anthropic', runtime: 'claude', unit: 'percent' }`, used by T-44-04.
    - Units are normalized by source only, never inferred from magnitude.
  - `CLAUDE_WINDOW_MINUTES = { five_hour: 300, seven_day: 10080 }`. It applies only to Claude named windows.
  - `COVERAGE = { codex_parent: 'unverified', codex_idle_baseline: 'unverified' }` (D-A4). These values are constant regardless of input.
  - `LABEL_PATTERN = /^[a-z0-9][a-z0-9._-]{0,63}$/`. `normalizeLabel(value)` returns `null` for a missing value and throws `INVALID_LABEL` for anything else that does not match, which includes any `@`.
  - `buildEnvelope(fields)` builds the envelope from an explicit object literal of the allow-listed fields only:
    - `schema`, `provider`, `runtime`, `source`, `account_label`, `attribution` (`'declared'` or `'unattributed'`).
    - `bucket_id`, `window_minutes`, `resets_at` (epoch seconds or `null`), `used_percent`.
    - `observed_at` (ISO or `null`), `freshness` (`'observed'`, `'file_mtime'` or `'unknown'`) and `concurrency` (default `'unknown'`; `'exclusive'` only when the caller declares it).
    - It never copies a deny-filtered object.
  - `validateEnvelope(value)` refuses any key outside the allow-list.
  - `fromTranscriptRows(rows, context)` returns `{ envelopes, warnings }`. It is total: malformed records become warnings and never throw. It works as follows:
    - Claude `rate_limit_event`: one envelope per `unifiedWindows` entry, with `bucket_id` equal to the window name and `used_percent = utilization × 100`. There is none for the top-level duplicate. `observed_at: null` and `freshness: 'unknown'`, unless `context.observedAt` is supplied with `context.freshness`.
    - Codex `event_msg` with `payload.type === 'token_count'` and `payload.rate_limits`: one envelope per non-null slot, with `bucket_id = '<limit_id>:<slot>'` (for example `codex:primary`), `window_minutes` as reported and `observed_at` from the row timestamp. A `null` `secondary` produces nothing. `primary`/`secondary` are never renamed to 5 h / 7 d.
    - `context.accountLabels` maps runtime to label, read through `normalizeLabel`. When the label is absent, `account_label: null` and `attribution: 'unattributed'`.
  - `summarize(envelopes, options)` returns `{ schema: SUMMARY_SCHEMA, version: 1, series, discontinuities, coverage: COVERAGE, verdict: 'inconclusive', status, warnings }`:
    - The series key is `provider, runtime, account_label, bucket_id, window_minutes`. Resets within `RESET_TOLERANCE_SECONDS = 60` are one reset; this constant is the recorded choice for assumption A4.
    - Each series has `first` and `last` (used_percent, resets_at), `samples`, and `delta` only for a continuous segment whose samples are all `concurrency: 'exclusive'`. Otherwise `delta: null` and `segment: 'inconclusive'`.
    - Discontinuity reasons form a closed set: `reset`, `decrease`, `account_label_change`, `unattributed`, `unknown_concurrency`, `window_change`.
    - There is no scalar total across series. With more than one provider, account or bucket there is no `total` key at all.
    - `status = { implemented: true, installed: envelopes.length > 0, behaviorally_verified: false, efficiency_measured: false }`. `verdict` is always `'inconclusive'` in this pass (D-X1): no matched cohorts exist.
- NEW `tests/unit/subscription-observation.test.cjs`. It uses `tests/unit/assert-harness.cjs` and loads every host shape from the captured fixtures through a `capturedLines` helper.

## Acceptance criteria

- The Claude executor fixture yields exactly two envelopes: `five_hour` at 70 with `window_minutes` 300, and `seven_day` at 57 with `window_minutes` 10080. The top-level duplicate is not a third bucket.
- The Codex parent fixture yields exactly three `codex:primary` envelopes with `used_percent` 1 and `window_minutes` 10080, and no envelope for `secondary: null`.
- Parent and child Codex samples whose `resets_at` differ by 1 s form one series with no `reset` discontinuity. A shift above the tolerance, a decrease, a label change or a window change each produces the named discontinuity.
- By default every segment is `inconclusive` and `delta` is `null`. A summary over two providers or two labels has no scalar total.
- `JSON.stringify` of every envelope and summary built from the Codex parent fixture contains none of `creator_user_id`, `<USER-ID>`, `credits`, `plan_type`, `balance` or `@`. A missing label gives `attribution: 'unattributed'`, and `normalizeLabel('a@b')` throws.
- `summarize(...).coverage` deep-equals `{ codex_parent: 'unverified', codex_idle_baseline: 'unverified' }`, `verdict === 'inconclusive'`, and `status` carries separate `installed`, `behaviorally_verified` and `efficiency_measured` booleans.
- A malformed `rate_limit_event` (a missing or non-numeric utilization) becomes a warning, and `fromTranscriptRows` does not throw.
- The module source requires none of `child_process`, `net`, `http`, `https` or `dgram`; a static test reads the file to check this.
- `node tests/unit/boundary-fixtures.test.cjs` passes with the new consumer and patterns.
