## Goal

P44-A, D-A1, D-A3, D-A4 and D-X1 (REQ-176, REQ-178, REQ-179, REQ-184). The usage reader reports `subscription_usage: null` today. This ticket fills that slot with the derived `shipyard.subscription-usage.v1` summary from T-44-01, built from the same explicit transcript sources. The token accounting, `observations`, `groups`, the top-level `warnings` and `comparable` stay exactly as they are. The Claude Stop hook bundles `usage-report.cjs` and swallows its exceptions, so any fault in the quota pass would otherwise silently drop the hook's token observations.

## Scope

- `usage-report.cjs`:
  - Add a literal top-level `require('./subscription-observation.cjs')`, so the hook bundler copies it.
  - After the token loop, build the summary from `sources` through `fromTranscriptRows` and `summarize`. The source kind is derived per row shape (Claude `rate_limit_event` → `claude-stream`, Codex `event_msg/token_count` → `codex-native`).
  - Wrap the whole pass so that any throw yields a summary whose `subscription_usage.warnings` names the failure. The top-level `warnings`, `comparable`, `observations` and `groups` never change because of quota data.
  - Set `subscription_usage` to the summary. When no quota record exists, keep the schema object with `series: []`, `verdict: 'inconclusive'` and `coverage` intact rather than `null`. `units` stays `'tokens processed; not subscription quota'`.
  - `options.accountLabels` (`{ claude?: label, codex?: label }`) is passed to the parser. CLI: repeatable `--account-label <runtime>=<label>`, where `<runtime>` is `claude` or `codex`. An invalid label or runtime exits 2 through the existing `parseCli` failure path. There is no automatic reading of private state here: without the option every observation is `unattributed` (D-A6).
  - Update the help text at `:945` to "Read-only; explicit transcript, attribution and outcome files only. JSON to stdout; no prompts. subscription_usage is derived from saved quota records and is never a price or token-to-quota conversion."
- `tests/unit/usage-report.test.cjs`: keep the file's existing `node:test` style. Add cases that load the captured Claude and Codex fixtures. After T-44-01 the `claude-stream` and `codex-agent-stream` manifests carry `inline_shapes` for `rate_limit_event` and `rate_limits`/`used_percent`, and this file is not a registered consumer of them. The malformed-record case therefore mutates a deep copy of a fixture-loaded row (for example, deleting `rate_limit_info.unifiedWindows.five_hour.utilization`) and never writes a quota record inline; this ticket does not edit the boundary manifests.
- `docs/usage-report.md`:
  - Replace line 78 with the `subscription_usage` contract: its fields, per-source units, no sums across provider, account or bucket, the discontinuity reasons, `coverage` `unverified` for the Codex parent and idle baseline, and `verdict: 'inconclusive'`.
  - Add the `--account-label` option.
  - Name the three transcript roots above as explicit paths the operator passes.
- Codex packaging: `make package-shipyard-codex` runs on the epic, not in this ticket.

- For the same inputs, `observations`, `groups`, `warnings` and `comparable` deep-equal the output of the same `report()` call before this change. The test pins them against values computed with `subscription_usage` removed.
