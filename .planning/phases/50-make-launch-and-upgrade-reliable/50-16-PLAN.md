## Scope

In `claude-delivery-host.cjs`: accept `--preflight` alone (worktree is the current directory) and `--preflight` together with the existing `--workflow ... --request-file ...` arguments; keep every other argv a usage error. Call preflight after the canonical-root check and before `createRunController`, with runtime `claude`, the host's `probeClaudeRuntime`, `scope: 'launch'`, `graphDir: inflightGraphDir(hostOptions, worktree)` (`claude-delivery-host.cjs:1087-1091`, the value that decides whether and where `recordInflight` writes at `:1138-1147`; `null` when it records none), and print through `emitPreflight`; a failure sets a non-zero exit before any controller state; the CLI wrapper prints `formatHint` for coded errors. In `claude-investigation-host.cjs`: accept `--preflight` and pass it through to the delivery CLI; add no second preflight call.
