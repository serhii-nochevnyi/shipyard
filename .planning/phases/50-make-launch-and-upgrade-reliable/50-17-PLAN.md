## Scope

`parseCli`: accept `--preflight` alone and `--preflight --args-file <json>`; keep `--capability-only` and `--args-file` exactly. In `runClaudeRoleCli` call preflight after parse and before `createClaudeRoleHost(...).run`, with runtime `claude`, the host's probe, `scope: 'launch'` and `graphDir` computed from the request with the host's own `graphDirectory` expression (`options.graphDir || <project root>/.planning/graph`, `:188-194`, the value `recordInflight` receives at `:1460`) but without that function's rejecting checks, because preflight must report an unavailable graph directory as a note and not throw before it has run; emit through `emitPreflight`. For `--capability-only` keep the stdout contract and exit 0 and add the hint line on stderr when the probe is unavailable. Build the identity at both sites with `repositoryIdentity`; the architecture-review subject this host builds (`phaseBinding` at `:489` and the re-check at `:1254`) takes its repository from the same `canonical.commonPath`, so converting `:179-180` converts that producer too.
