## Scope

Explicit sources: `CODEX_HOME` (env or flag) and the capability file (`SHIPYARD_CODEX_CAPABILITIES_FILE` env or the host's `--capabilities-file` flag). Installed mode: a home agrees when its realpath equals the bundle's home; a capability file agrees when its realpath equals the bundle copy or its bytes hash to `manifest.capabilities_digest`. Source mode: capability evidence stays explicit (flag, then env file, then `CODEX_HOME/shipyard/codex-capabilities.json` only when `CODEX_HOME` is set; otherwise `RUNTIME_CAPABILITY_MISSING`); the Codex home accessor returns the explicit value, else `~/.codex`. Add `resolveCodexHome({ scriptDir, env, flags })`, `resolveClaudeHome({ env })` (`CLAUDE_CONFIG_DIR`, else `<env.HOME or os.homedir()>/.claude`), a Claude-runtime branch of `resolveHostEnvironment` that carries no Codex values and never refuses on a Codex variable, and `RESOLVER_CODES` (frozen list of the codes the module can throw). `SHIPYARD_CODEX_AGENT_DIR`, `SHIPYARD_CODEX_LOG_DB`, `SHIPYARD_GRAPH_DIR` and `GSD_*` are not checked or rewritten.

## Out of scope

Converting call sites (later tickets), the preflight library, any change to credential scrubbing, the installer, README.

## Acceptance criteria

- Matrix tests: flag and env agreeing (including through a symlinked home and a capability file with identical bytes at another path) accept; disagreeing home, disagreeing capability path with different bytes, and a flag/env pair that disagree with each other refuse with `ENV_CONFLICT` and a message containing both values.
- `launchEnvironment(resolved, baseEnv)` returns a copy of `baseEnv` whose Codex home, capability path and runtime keys are the validated values and whose every other key is byte-identical; a Claude resolution adds no Codex keys.
- A host run with a Claude runtime and conflicting Codex variables does not refuse.
- Every code in `RESOLVER_CODES` is present in `LAUNCH_CODES` of `refusal-hints.cjs` once T-50-02 has merged; this ticket asserts that only if that module exports the list at test time, otherwise the later contract test (T-50-22) owns the check.
