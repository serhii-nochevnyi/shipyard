<objective>Make the one hint map complete and accurate for launch and upgrade, apply one checkout-relative-remedy rule to every entry in it, and define the exact new code names that later tickets emit, so every refusal reaches the operator with a supported remedy.</objective>

## Goal

ADR-030 L-6, REQ-199 ("a remedy that runs from the installed bundle") and the failure class of INV-017: a refusal such as `RUNTIME_UNAVAILABLE` whose remedy says "Install and authenticate the runtime" while the real cause was missing capability evidence, `ARCHIVE_AUTHORITY_BUSY` with no hint at all, or a remedy of `make install-shipyard-codex` that an installed user has no checkout to run, leaves the operator needing internal host knowledge.

## Scope

Rule and scope (one, stated once): every entry of `HINTS`, including the four that predate this ticket, must have a remedy whose commands are either a documented marketplace command or a `node {bundle}/scripts/<script>` invocation of a script that ships in the bundle; no remedy names `make`, a `plugins/delivery-pipeline/` or bare `scripts/` path, an `install-shipyard-` installer or `ensure-gsd-core.sh` (all checkout-relative), a bypass word, or the deletion, archiving or moving of history. Entries whose remedy is "fix the request" carry no command and satisfy the rule trivially.

Changes: rewrite `REFERENCE_UNAVAILABLE`, `STALE_GENERATED_AGENT`, `CODEX_CONFIG_FIX` and `CODEX_GENERATED_AGENT_FIX` so that only their command forms change (their hint text and the condition each names stay): the first two and the last point to the documented marketplace upgrade commands (the Codex pair, or the Claude install command), and `CODEX_CONFIG_FIX` becomes `Fix {key} in .planning/config.json, then run: node {bundle}/scripts/gsd-tune.cjs --runtime codex --apply.` Rewrite the misleading `RUNTIME_UNAVAILABLE`. Add entries for the existing codes above that lack one. Define these new codes now so later tickets use the exact strings: `ENV_CONFLICT`, `BUNDLE_MANIFEST_INVALID`, `CAPABILITY_EVIDENCE_STALE`, `CAPABILITY_SNAPSHOT_AGED` (warning-only), `LEGACY_HISTORY_UNSAFE`, `LEGACY_HISTORY_CHANGED`, `LEGACY_HISTORY_UNKNOWN_MEMBER`, `LEGACY_HISTORY_COLLISION`, `LEGACY_HISTORY_MISSING` (warning-only), `REPOSITORY_IDENTITY_INVALID`. Extend `formatHint` to `formatHint(code, vars)` with `{name}` tokens such as `{host}`, `{bundle}`, `{explicit}`, `{bundle_value}`, `{path}`, `{pid}`, `{label}`, `{since}`. `{bundle}` has one built-in default so hints printed by wrappers that pass no vars are still copy-pasteable: the absolute path of the directory above the one that contains this module (the installed bundle root, or `plugins/delivery-pipeline` in a checkout); an explicit var wins, and every other unsupplied token stays visible.

## Out of scope

Changing which code a module throws, adding preflight or host wiring (later tickets), changing the meaning of any existing entry (hint text and the condition named stay as they are; only command forms in the four rewritten remedies change), any ADR-014 policy change.

## Acceptance criteria

- Every code listed in Scope and in Context has a frozen entry with non-empty hint and remedy; the module also exports the list of launch and upgrade codes (`LAUNCH_CODES`) so later tests assert coverage against one list.
- `formatHint(code)` output for existing codes is byte-identical to before except for the five deliberately rewritten entries (`REFERENCE_UNAVAILABLE`, `RUNTIME_UNAVAILABLE`, `STALE_GENERATED_AGENT`, `CODEX_CONFIG_FIX`, `CODEX_GENERATED_AGENT_FIX`); `formatHint(code, vars)` replaces `{token}` for every supplied var, fills `{bundle}` when unsupplied and leaves every other unsupplied token visible (`CODEX_CONFIG_FIX` still shows its literal `{key}` when no var is given).
- The rule holds for the whole map: a scan over every value of `HINTS` and the default entry finds no remedy containing `make `, `plugins/delivery-pipeline/`, a `scripts/` path not preceded by `{bundle}/`, `install-shipyard-`, `ensure-gsd-core` or any word from the bypass rule, and every remedy that mentions provenance, history, sidecars, the catalogue or authority contains none of delete, remove, archive, move, rename, purge or clean.
- Remedies for `RUNTIME_UNAVAILABLE`, `RUNTIME_CAPABILITY_MISSING`, `CAPABILITY_EVIDENCE_STALE`, `BUNDLE_MANIFEST_INVALID` and `STALE_GENERATED_AGENT` distinguish missing evidence, stale evidence, a missing CLI and an outdated install, and point to the documented marketplace upgrade command or to `node {bundle}/scripts/{host} --preflight`.
- `ENV_CONFLICT` names both values via tokens and offers two remedies (unset the variable, or reinstall into the named home). `LEGACY_HISTORY_UNKNOWN_MEMBER` tells the operator to update the host that wrote the file. `ARCHIVE_AUTHORITY_BUSY` tells the operator to wait for the other session and re-run, and explains that a process which reused a crashed owner's pid must end first.
- The existing `refusal-hints.test.cjs` assertions pass, with the single deliberate change that `CODEX_GENERATED_AGENT_FIX` is asserted against the marketplace upgrade command instead of `install-shipyard-codex`; it is named in the SUMMARY.
