## Goal

REQ-149c (D-14): when a Codex launch is refused because of project or host configuration (for example a `model_profile` or model key in `.planning/config.json` that the Codex grid does not accept), the refusal names the configuration fix: the file, the key, and the exact `gsd-tune.cjs --runtime codex` command. It no longer tells the operator to reinstall Codex. Refusals caused by a stale or missing generated agent keep the reinstall remedy.

## Scope

- `refusal-hints.cjs`: add a config-cause hint whose text names `.planning/config.json`, the offending key (passed in details), and `node <plugin>/scripts/gsd-tune.cjs --runtime codex --apply`. Add a generated-agent-cause hint that keeps the reinstall text. Map the existing refusal codes to one of the two causes. Codes that are not listed keep today's text, so nothing becomes vaguer.
- `codex-model-remap.cjs`: replace the single `REPAIR` constant with a function `repairFor(code, details)` that delegates to `refusal-hints.cjs`. Keep exporting `REPAIR` as the generated-agent text so current importers still load.
- `codex-agent.cjs`: `fail(message, code, details)` appends `repairFor(code, details)`. Pass the config key in `details` at the config-validation refusal sites (the `:187` path and its siblings).
- `codex-dispatch-adapter.cjs`: use `repairFor` where it currently appends `REPAIR`.
- Tests: `codex-agent.test.cjs`: a config-caused refusal message contains `gsd-tune.cjs --runtime codex` and the key name, and does not contain `install-shipyard-codex.sh`; a stale-variant refusal still names the reinstall. `refusal-hints.test.cjs`: both new hints are registered and formatted. `codex-dispatch-adapter.test.cjs`: an adapter-level config refusal carries the config remedy.
- Comment policy on added lines.

## Out of scope

- Changing which configurations are refused (ADR-014 boundary unchanged).
- `gsd-tune.cjs` itself (T-40-05).

## Acceptance criteria

- A refusal caused by a project config key names that key, `.planning/config.json` and the gsd-tune command, and has no reinstall text.
- Refusals for missing or stale generated agents are byte-identical to today's.
- Error codes are unchanged, so existing `code ===` assertions still pass.
