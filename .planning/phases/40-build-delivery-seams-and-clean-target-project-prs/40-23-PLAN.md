## Goal

This is the release gate (D-01, D-06, D-21, D-22).

- `tests/live/live-round.sh --runtime claude|codex` copies an in-repo fixture project into `$TMPDIR` and pushes it to a throwaway GitHub repository. It then runs one real research → decompose → executor → sentinel round through the installed-layout hosts and the dispatch entry point, using each role's base rung of its runtime grid, and writes a live receipt.
- `scripts/release.sh` refuses to cut a release unless a passing receipt exists for the current plugin version and tree sha, for both runtimes, and is at most 7 days old.

`make test-live` and `make release` wrappers are added by T-40-26.

## Scope

- NEW `tests/fixtures/live-project/`: a minimal target project with no Shipyard manifest, so hygiene applies:
  - `README.md` describes the project and names no tooling;
  - `Makefile` has a `test` target running `node tests/greeting.test.cjs`;
  - `src/greeting.cjs` has one exported function;
  - `tests/greeting.test.cjs` has one assertion;
  - `planning/architecture/ADR-001-greeting-formats.md` is an accepted ADR with `UI design: none` that asks for one small, two-ticket change. `live-round.sh` copies the `planning/` directory to `.planning/` in the scratch copy, where it stays untracked per D-16.
- NEW `tests/live/live-round.sh --runtime <claude|codex> [--repo owner/name]`:
  - `set -euo pipefail`, bash 3.2.
  - Preconditions checked early: the runtime CLI is on `PATH`, `gh auth status` succeeds, `SHIPYARD_LIVE_REPO` or `--repo` names a throwaway repository, and the installed hosts are the release layout.
  - Stages: copy the fixture to `mktemp -d`; push to the repo's default branch; run investigate research, decompose, one executor via `deliver-dispatch.cjs launch` + `wait`, and one sentinel round; run `pr-hygiene.cjs check` on the produced PR.
  - Each stage writes `{stage, ok, detail, dispatch_id}`.
  - At the end it calls `live-receipt.cjs write` and prints the receipt path. Any failure writes a failing receipt and exits non-zero.
- NEW `plugins/delivery-pipeline/scripts/live-receipt.cjs`:
  - `write({version, tree_sha, head_sha, runtime, stages, cli_version})` → `~/.local/state/shipyard/live/<version>/<tree_sha>/<runtime>.json` (overridable with `SHIPYARD_LIVE_STATE_DIR` for tests), written atomically.
  - `check({version, tree_sha, runtimes: ['claude', 'codex'], maxAgeDays: 7, now})` returns `{ok, missing, stale, failed}`.
  - CLI `write|check`.
- NEW `scripts/release.sh <version>`:
  - Refuses when `<version>` differs from `plugin.json`, the tree is dirty, or `live-receipt.cjs check` fails, naming the missing or stale runtime and the command `bash tests/live/live-round.sh --runtime <r>`.
  - Otherwise runs `bash tests/smoke/release-notes-smoke.sh` and creates the annotated tag `v<version>`.
  - Prints the push command; it does not push.
- NEW `tests/unit/release-gate.test.cjs` (offline, `SHIPYARD_LIVE_STATE_DIR` in `os.tmpdir()`, injected `now`):
  - both runtimes passing and fresh → ok;
  - one runtime missing → refused naming it;
  - an 8-day-old receipt → stale;
  - a failed stage → failed;
  - a receipt for another tree sha is ignored;
  - `release.sh` in a hermetic temp git repo (own `GIT_CONFIG_GLOBAL`, `commit.gpgsign=false`, `tag.gpgsign=false`) refuses without receipts and tags with them.
- Comment policy on added lines.

## Acceptance criteria

- `scripts/release.sh` cannot create a tag without two fresh passing receipts for the exact version and tree.
- The live round fails its receipt if the produced PR violates hygiene.
- `tests/unit/release-gate.test.cjs` runs offline.

## Test strategy (TDD: failing test first)

1. RED: write `tests/unit/release-gate.test.cjs`. Run it; it fails because `live-receipt.cjs` and `release.sh` do not exist.
2. GREEN: implement `live-receipt.cjs`, then `release.sh`, then the fixture project and `live-round.sh`.
3. Re-run the unit test, `bash -n tests/live/live-round.sh`, and `make -C tests/fixtures/live-project test`.
4. **checkpoint:human-action** (needs both CLIs logged in, `gh` auth, network and a throwaway GitHub repository; this runs only after phase 39 is released and the build from this branch is installed with `make install-shipyard-claude-hook` and `make install-shipyard-codex`). The operator sets `SHIPYARD_LIVE_REPO=<owner>/<throwaway>` and runs `bash tests/live/live-round.sh --runtime claude` and then `--runtime codex`. They confirm both print a passing receipt path under `~/.local/state/shipyard/live/`, and reply with the two receipt paths, or with the failing stage and detail.
