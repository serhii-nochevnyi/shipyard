## Scope

- `codex-delivery-host.cjs`:
  - For `role: 'research'` with an investigation scope, compute the four line artifact paths from the scope (host-derived, never from agent output).
  - Launch each line through the existing boundary path.
  - After each child returns, call `assertContained` for that line's artifact.
  - When all four exist, return `sealResearch(...)`.
  - When some lines are sealed and one fails, return a structured failure naming the failed line and its cause and listing the sealed lines. Build it with the sealer's `researchLineFailure` (T-40-10), which T-40-13 also uses on Claude, so both runtimes return one shape.
- `tests/unit/codex-delivery-host.test.cjs`, with a stubbed launch per line that writes files into an `os.tmpdir()` worktree:
  - four clean lines produce the envelope;
  - a line writing outside its artifact refuses `CONTAINMENT_VIOLATION` naming the line;
  - a missing artifact names the line and `RESEARCH_LINE_MISSING`;
  - a request with ticket `type` in `signals` is still refused by the boundary (regression guard for Pitfall 1).
