## Goal

ADR-018 decision 3 (D-43, D-44): one module defines the scratch and host-owned files and the launch preconditions for every role, delivery and decompose host. Every refusal carries a command the operator can copy and run. The module also provides the lstat-based snapshot, diff and restore helpers that the hosts use for REQ-154 (restore of out-of-scope mutations), and the plan materialization helper that makes "plan inside the worktree" satisfiable in target projects (D-47).

This ticket creates the module only. The hosts are wired in T-40-32 (role host), T-40-33 (delivery and decompose hosts) and T-40-34 (`ticket-worktree.sh`, finalizer, base-merge). The T-40-22 provenance sidecar and the T-40-03 PR ledger enter the host-owned set in T-40-29.

## Scope

1. NEW `plugins/delivery-pipeline/scripts/worktree-conditions.cjs`, `REGISTRY`: frozen entries `{path, kind: 'file'|'dir', class: 'scratch'|'host-owned', base: 'worktree'|'graph'}`.
   - Scratch (base `worktree`), built from the `role-artifact.cjs` exports: `PR_BODY_NAME`, `EVIDENCE_NAME`, `MANIFEST_NAME`, `REPAIR_EVIDENCE_NAME`, `DRIFT_EVIDENCE_NAME`, the `JUDGMENT_EVIDENCE_NAMES` values except `INTEGRATION.md`, and `ARTIFACT_ARCHIVE_DIR/` as a dir.
   - Host-owned (base `graph`): `dispatches.json`, `delivery-front.json`, `delivery-state.json`, `delivery-state.yaml`, `delivery-state-meta.json`.
   - Export `scratchPaths()`, `hostOwnedPaths(graphDir, worktree)` and `excludeLines()` (sorted, one anchored line per scratch entry, for example `/.shipyard-pr-body.md` and `/.shipyard-role-artifacts/`).
2. `classify(worktree, graphDir, {run})`: runs `git status --porcelain=v1 -z --untracked-files=all --ignored` through the injected runner. It returns `{trackedDirty[], untrackedUnknown[], scratchPresent[], hostOwnedDirty[]}`. Ignored entries (`!!`) that match a registry path are `scratchPresent` or `hostOwnedDirty`. Any other ignored entry (for example a gitignored `.planning/` copy in a target project, `node_modules/`, or the stop-gate ledger) is not `untrackedUnknown` and never refuses a launch. Only `??` entries outside the registry are `untrackedUnknown`. A path tracked in HEAD is never scratch (the Shipyard repository tracks three files under `.shipyard-role-artifacts/`). Host-owned graph paths inside the worktree are reported in `hostOwnedDirty`, never in `trackedDirty` (Pitfall 5).
3. `check(profile, {worktree, graphDir, base, evidencePath, planPath, commits, stateRoot, run, gpg})`, profiles `arch-review`, `pr-sentinel`, `integrator`, `drift-check`, `executor`, `repair`, `decompose`, following the precondition matrix in 40-RESEARCH-ADR018.md Pattern 1. `drift-check` uses the `arch-review` column: clean tracked tree, no unknown untracked files, own evidence absent, plan inside the worktree, fresh base ref, no signing. Each profile's own evidence set comes from the `role-artifact.cjs` exports and is exported as `EVIDENCE_BY_PROFILE`: `arch-review`, `pr-sentinel` and `integrator` from `JUDGMENT_EVIDENCE_NAMES`, `drift-check` from `DRIFT_EVIDENCE_NAME`, `repair` from `REPAIR_EVIDENCE_NAME`, and `executor` from `PR_BODY_NAME`, `EVIDENCE_NAME` and `MANIFEST_NAME`. `decompose` has none.
   - Graph inside the worktree (D-47, D-54): `GRAPH_OUTSIDE_WORKTREE` is checked only when `.planning/` is tracked at the worktree HEAD. When `.planning/` is untracked (a target project), the graph stays host-side for every profile. `check` then requires that the supplied `graphDir` exists, is outside the worktree, and resolves through `resolveGraphDir`. No refusal may carry a remedy that cannot clear it. It returns `{ok: true, movedAside: []}` or throws an error with `{code, message, remedy, details}`. Codes: `WORKTREE_NOT_READY` (not the canonical toplevel), `WORKTREE_DIRTY` (tracked change outside host-owned), `UNTRACKED_UNKNOWN`, `EVIDENCE_PRESENT` (a symlink or non-regular own evidence), `PLAN_OUTSIDE_WORKTREE`, `GRAPH_OUTSIDE_WORKTREE`, `STATE_INSIDE_WORKTREE`, `BASE_FETCH_FAILED`, `BASE_DIVERGED`, `BASE_REVISION_UNAVAILABLE`, `SIGNER_UNAVAILABLE`. Each `remedy` is one command with absolute paths, for example `git -C /abs/wt status --porcelain`, `git -C /abs/wt fetch --no-tags origin +refs/heads/<b>:refs/remotes/origin/<b>`, or `bash <plugin>/scripts/ticket-worktree.sh create <T> <branch> <base>`.
   - Own evidence (Pitfall 3): an untracked regular own evidence file is moved aside into `<stateRoot>/moved-aside/<sha256>` and reported in `movedAside: [{path, sha256}]`. A tracked own evidence file (for example `INTEGRATION.md`) is left for `prepareRoleArtifact` rotation. A symlink or non-regular file refuses `EVIDENCE_PRESENT`.
   - Signing: `signerFingerprint({worktree, run, gpg})` moves the gpg listing from `claude-delivery-host.cjs:184-202` here unchanged in meaning: `user.signingkey` must resolve to exactly one secret key and a full fingerprint. It is checked for `executor`, `repair`, and for `pr-sentinel` only when `.planning/graph` is tracked.
   - Base freshness: fetch with the `branchOid` refspec, require `origin/<b>`, refuse when the local `<b>` has diverged. Not checked for `decompose`.
4. `snapshot({worktree, graphDir, run})`, `diffSnapshot(snap, {allowed})` and `restore(worktree, diff, {run})`, per Pattern 3:
   - The snapshot holds HEAD, branch, the untracked set (lstat per registry entry, independent of `info/exclude`), and the bytes of every scratch and host-owned file under the worktree, each bounded at 1 MiB (refuse `SNAPSHOT_TOO_LARGE`), plus a recursive listing with sha256 digests of `.shipyard-role-artifacts/`.
   - `diffSnapshot` returns `{tracked[], created[], rewritten[], archive[], head}` minus `allowed`. `allowed` is either a list of exact repo-relative paths or a predicate `(path) => boolean`, so that a host can pass a `path-owner.cjs` `owns(parse(decl), p)` test over the ticket's declared files.
   - `restore` does four things: tracked paths via `git restore --source=HEAD --staged --worktree -- <paths>`; `created` paths unlinked only after lstat proves each segment resolves inside the worktree realpath and the path is untracked and not in the snapshot, then empty directories are removed bottom-up; `rewritten` bytes are written back atomically; a HEAD move on an unchanged branch uses compare-and-swap `git update-ref refs/heads/<branch> <snap.head> <current>` then `git reset --keep <snap.head>`, and a branch switch refuses `STALE_CONTEXT` with the remedy `git -C <wt> switch <branch>`. It never follows symlinks and never runs `git clean`. It returns `{restored, removed, rewritten}`.
5. `materializePlan({worktree, ticket, graphDir, run})` (D-47): when `.planning/` is not tracked at the worktree HEAD, copy only the ticket's plan file (`tickets.json` row `plan`, resolved from the main checkout graph via `resolveGraphDir`) to the same repo-relative path inside the worktree. The copy is atomic and idempotent. It replaces an existing copy whose sha256 differs from the source, so re-running the `ticket-worktree.sh create` remedy after a replan clears the refusal. It returns `{path, sha256}`. `resolvePlan({worktree, planPath})` returns the in-worktree plan path when `planPath` is inside the worktree, or when an in-worktree copy at the same repo-relative path has an equal sha256. Otherwise it refuses `PLAN_OUTSIDE_WORKTREE` with the `ticket-worktree.sh create` remedy.
6. CLI: `verify --worktree <wt> --role <role> [--graph <dir>] [--base <b>] [--json]` (exit 0 ok, 1 refusal with the remedy on stderr or in the JSON), `exclude-lines`, and `materialize-plan --worktree <wt> --ticket <T> [--graph <dir>]`. Unknown flags refuse. All git and gpg calls use `execFileSync` argument arrays with `--` before pathspecs.

8. Comment policy on added lines.

## Acceptance criteria

- Registry scratch names equal the `role-artifact.cjs` exports, asserted by a test that imports both.
- A tracked file under `.shipyard-role-artifacts/` that was modified is reported as `trackedDirty`, never as scratch.
- Every refusal code has a `remedy` that is a single command containing the absolute worktree path, and running that remedy can clear the condition.
- Every profile, including `drift-check`, is satisfiable in a target project whose `.planning/` is untracked and gitignored.
- Snapshot and restore detect and undo a rewrite of a scratch file even when that file is listed in `info/exclude`.
- Restore never deletes a path outside the worktree, never follows a symlink, and never touches a path present in the snapshot.
- `exclude-lines` output is sorted and byte-stable across runs.
