## Goal

ADR-018 decisions 8 and 9 (D-49, D-50).

- Arch-review accepts a draft PR, because deliver undrafts only after `conform`. The sentinel and the merge gate keep refusing drafts, and a new test pins the merge refusal.
- A sentinel round excludes PRs opened after its snapshot. It never acts on them or reports them. Changed members still expire.

## Scope

1. Arch-review identity (`:363` and `:826`): drop `live.isDraft === true` from the refusal condition. Split the combined message into one refusal per cause, each naming a remedy:
   - not open → `gh pr view <n> --json state`;
   - head differs → `git -C <wt> pull --ff-only origin <branch>`;
   - base differs → `gh pr view <n> --json baseRefName`.
   Code `STALE_CONTEXT`.
2. `prepareSentinel` and every pr-sentinel check keep treating drafts as not certified. No change to `pr_state.draft`.
3. `revalidateLiveInputs` pr-sentinel branch:
   - `:841-848` a non-member now `pr-open` in the graph is excluded silently from this round;
   - `:862-867` a member with an additional open PR expires (`expiredTickets.push(id)`) instead of rejecting;
   - `:885-891` a non-member with an open PR on GitHub is excluded silently, but a non-array `open` (gh failure) still rejects `STALE_CONTEXT`;
   - `:838-840` a membership change in the graph still rejects.
   Excluded tickets are added to neither the result, nor the round record, nor the artifact.
4. `tests/unit/claude-role-host.test.cjs` new cases:
   - arch-review on an `isDraft: true` PR seals `conform`;
   - revalidation passes when the PR is drafted or undrafted mid-run;
   - a non-member opens a PR mid-round (fixture mutation inside `onLaunch`), and the round seals with `result.round.tickets` equal to the snapshot;
   - the graph marks a non-member `pr-open` mid-round, with the same outcome;
   - a member gains a second open PR and appears in `expired_tickets`;
   - a non-array `listPullRequests` for a non-member gives `STALE_CONTEXT`.
5. NEW `tests/unit/sentinel-draft-merge.test.cjs`: drives `sentinel.cjs merge` against a stub `gh` on `PATH` that returns `isDraft: true`, and asserts the block message and that no `gh pr merge` call was made. Hermetic via `assert-harness.cjs`.
6. Comment policy on added lines.

## Acceptance criteria

- An arch-review of a draft PR is never refused because it is a draft.
- `sentinel.cjs merge` refuses a draft PR, pinned by a test.
- A PR opened by a non-member during a round never appears in that round's result, record or artifact, and does not fail the round.
- A changed member still expires. A gh failure is still a refusal (fail closed).
