## Goal

In target projects (D-07, D-19), the executor PR body accepted by the host does not start with `Ticket: <ID>` and passes the hygiene check. The host-finalized commit subject is a conventional commit without the ticket id. In the Shipyard repository (exempt, D-26) both keep today's behaviour.

The applicability decision is computed inside these trusted modules with `prHygiene.applies({root, ref: <base>})`, from the committed base. It is never read from the worktree's files and never taken from agent output. The executor's body guide comes from the entry point through the existing `prBodyGuide` argument (T-40-15 passes `NEUTRAL_PR_BODY_GUIDE`), so `executors.mjs` needs no change.

## Scope

- `role-artifact.cjs`: at both call sites, compute `hygiene = applies({root, ref: base})` from the trusted root and base already passed to them.
  - When `hygiene` is false, keep `assertTicketMarker` unchanged.
  - When true, require a non-empty body that passes `prHygiene.check({body})`. A body starting with `Ticket:` fails with `PR_BODY_LEAK`, listing the violations.
  - If a call site has no trusted base in scope, use the root's `origin/HEAD` and document that choice in the evidence. Do not widen the function signature from agent-supplied data.
- `delivery-commit-finalizer.cjs`: when hygiene applies to the finalizer's root and base, the subject is `<type>: <ticket title with a lowercased first letter>`, with `<type>` from D-27, and it must pass `prHygiene.check({commits: [subject]})` or the finalizer refuses. When exempt, keep `(${ticket}): finalize scoped changes`. Callers that pass nothing new behave as today in the Shipyard repository.
- Tests:
  - `tests/unit/role-artifact.test.cjs` (hermetic git fixtures in `os.tmpdir()`, one with a committed `shipyard` manifest and one without): exempt with marker passes; target with marker fails `PR_BODY_LEAK`; target with a neutral body passes; a target worktree that adds an uncommitted `shipyard` manifest is still treated as a target.
  - `tests/unit/delivery-commit-finalizer.test.cjs`: a target subject is conventional and id-free, and an exempt subject is unchanged.
