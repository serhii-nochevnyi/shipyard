## Scope

- `codex-decompose-host.cjs`:
  - `gsd-phase-researcher` sandbox becomes `workspace-write`; `gsd-plan-checker` stays `read-only`.
  - The researcher's allowed artifact is the phase research path computed by the host from the scope (`.planning/phases/<phase-dir>/<NN>-RESEARCH.md`), never taken from agent output.
  - After a researcher run, call `assertContained({worktree, allowed: [artifact]})`, then seal the artifact reference through the sealer.
  - After a planner run, call `sealDecomposition` over the written plans; a planner's containment set is the phase directory.
  - Return the envelope.
- `codex-dispatch-adapter.cjs`: `expectedSandbox` default is `workspace-write` for `gsd-phase-researcher` and the investigation researcher variant, and stays `read-only` for `gsd-plan-checker`. An explicit `selection.sandbox_mode` still wins.
- `gsd-tune.cjs` `codexStaticVariants`: `research` → `workspace-write`; `arch-review` and `drift-check` stay `read-only`. The generated agent TOML carries the new sandbox. Codex output changes only after `make install-shipyard-codex`.
- `tests/unit/codex-decompose-host.test.cjs`:
  - Generate the agent file with `gsd-tune.cjs codexStaticVariants` / the generator function in `os.tmpdir()`, instead of the forged literal.
  - Cases: a researcher writing only its artifact returns a sealed result; a researcher that also edits a source file refuses `CONTAINMENT_VIOLATION`; the plan-checker is still `read-only`; a planner returns a decomposition envelope with an index.
  - The existing captured-stream replay (0.155.1 fixtures) keeps working.
  - Add no new inline Codex exec-stream or session record. The file stays in the boundary registry's `migrating` list until T-40-09 migrates it.
- `tests/unit/codex-dispatch-adapter.test.cjs`: default sandbox per role.
- `tests/unit/gsd-tune.test.cjs`: static variant sandboxes.
