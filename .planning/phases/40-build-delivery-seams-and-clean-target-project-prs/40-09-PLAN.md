## Goal

REQ-148 part C5 (D-13). A Codex parent can no longer relay a shortened or rewritten task to its child without the host noticing:

- The host writes the full task to a host-owned file outside the model-writable tree.
- The parent receives only the path and the sha256.
- After the run, the host verifies from the child's native session evidence that the child received exactly that path and digest, and that the file is unchanged.
- Unverifiable evidence is a refusal (RISKS R12).

The Codex boundary fixtures are re-captured from the real CLI with the new launch shape (D-02).

## Scope

- `codex-runtime-host.cjs`:
  - Before launch, write the full task to `<run store>/tasks/<dispatch or run id>.md` with mode 0600 under the existing host state root (never inside the worktree), and compute sha256 with `node:crypto`. Refuse `INVALID_STATE_DIR` if the path resolves inside the worktree.
  - The parent prompt names only `TASK_FILE=<abs path>` and `TASK_SHA256=<hex>`, plus the existing spawn instructions: the child must read that file and follow it exactly.
  - After the run, require that the child's first user/developer message contains both exact values, and that the file's sha256 is unchanged. Otherwise refuse with a new code (for example `TASK_RELAY_UNVERIFIED`) naming what was missing. Remove the file after verification.
  - Keep the existing spawn-evidence checks.
- `tests/fixtures/captured/codex-agent-stream-{parent,child}.jsonl`: re-captured with the new launch shape through `scripts/capture-boundary-fixtures.cjs --boundary codex-agent-stream` (human-action checkpoint).
- `tests/fixtures/captured/boundaries/codex-agent-stream.json`: add the two new fixtures and the captured `cli_version`. Point the `codex-runtime-host.test.cjs` consumer at them. Keep the 0.155.1 files listed for the decompose consumer, which is migrated separately.
- `tests/unit/codex-runtime-host.test.cjs`: replay the new captures.
  - The happy path verifies the digest.
  - Refusal cases derive a mutated copy of the captured child stream in the test by a byte substitution on the path or digest value. This is allowed because it mutates a real capture rather than authoring records: a shortened task path refuses; a wrong digest refuses; a file modified after launch refuses; a missing child message refuses.
  - The task file is created outside the worktree with mode 0600.
