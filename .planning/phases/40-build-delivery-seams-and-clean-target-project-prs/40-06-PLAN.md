## Goal

The pinned digests of the runtime-owned files (`runtime-adapters.cjs`, `claude-dispatch-adapter.cjs`) can change only through `scripts/refresh-runtime-digests.cjs`. Every commit that changes the pin carries a `Runtime-Digest-Refresh:` trailer naming each refreshed file, and CI rejects a pin change without it (D-10). The `make refresh-runtime-digests` target that wraps the script is added by the command-surface ticket T-40-26.

- `tests/unit/source-contract.test.cjs:1986-1999` (anchor A16): the inline `RUNTIME_OWNED_FILE_DIGESTS` object and the native-grid assertions that follow it. T-39-12 changed this digest by hand, which is exactly the pattern this ticket replaces.
- `.github/workflows/test.yml:42-46`: checkout already uses `fetch-depth: 0`; Node pinned at 24.15.0; `make test-fast` step.

## Scope

- NEW `tests/unit/runtime-file-digests.json`: `{schema: 'shipyard.runtime-file-digests.v1', files: {<repo path>: <sha256>}}` with the two current digests (computed, not copied from the test).
- `tests/unit/source-contract.test.cjs`: load the digests from the JSON file instead of the inline object. Keep the equality assertion and the native-grid assertions unchanged. Fail with a message naming `node scripts/refresh-runtime-digests.cjs` when a digest differs.
- NEW `scripts/refresh-runtime-digests.cjs`: recompute sha256 for every listed file, rewrite the JSON deterministically (sorted keys, trailing newline), and print the exact trailer lines to add, one `Runtime-Digest-Refresh: <path>` per changed file. `--check` exits non-zero without writing when any digest is stale. It refuses when a listed file is missing.
- NEW `scripts/check-runtime-digest-trailer.cjs --base <ref>`: for every commit in `<base>..HEAD` that modifies `tests/unit/runtime-file-digests.json`, parse the commit message trailers (`git log --format=%B`, last-trailer-block semantics). Require one `Runtime-Digest-Refresh: <path>` for each path whose digest changed in that commit. Exit non-zero naming the commit and the missing path. Use `execFileSync` argument arrays with no shell.
- NEW `tests/unit/runtime-digests.test.cjs`: a hermetic git fixture in `os.tmpdir()` (own `GIT_CONFIG_GLOBAL`, `commit.gpgsign=false`) with a copy of the two files and the JSON. Cases: refresh rewrites a stale digest and prints the trailer; `--check` fails on a stale pin; the trailer checker passes an annotated pin commit, fails an unannotated one, fails a trailer naming the wrong file, and ignores commits that do not touch the JSON.
- `.github/workflows/test.yml`: before `make test-fast`, add a step that runs `node scripts/check-runtime-digest-trailer.cjs --base "origin/${{ github.base_ref || 'main' }}"` on pull requests. Keep the existing steps.
- Comment policy on added lines.
