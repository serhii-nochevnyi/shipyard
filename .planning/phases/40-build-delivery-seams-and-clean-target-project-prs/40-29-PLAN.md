## Goal

ADR-018 decision 3 and RISKS R4 (D-45). After T-40-22, every in-flight dispatch writes `<graphDir>/provenance/<dispatch_id>.json`, and `recordInflight` writes `dispatches.json`. When a role host uses its default graph (`<worktree>/.planning/graph`), both land inside the ticket worktree. Unless they are host-owned, every arch-review after T-40-22 fails with `WORKTREE_MUTATED`, and the next launch refuses.

This ticket adds `provenance/` (a dir) and `pr-ledger.json` (T-40-03, D-31) to the registry's host-owned graph entries. It proves the result against the real `dispatch-record.cjs` and `pr-ledger.cjs`. T-40-22 is not rewritten.

## Scope

1. `worktree-conditions.cjs` `REGISTRY`: add the host-owned graph entries `provenance/` (kind `dir`) and `pr-ledger.json` (kind `file`). Import the provenance dir name from `dispatch-record.cjs` if T-40-22 exports it. Otherwise define it once in the registry and assert its equality with the path `readProvenance` reads in the test.
2. `classify` and `check`: files under a host-owned dir are `hostOwnedDirty`, whether they are tracked or untracked. They never make a launch refuse as `UNTRACKED_UNKNOWN` or `WORKTREE_DIRTY`.
3. `snapshot` and `diffSnapshot`: include every file under host-owned dirs, bounded as for other host-owned files. A sidecar that the host wrote before the snapshot is unchanged. A sidecar rewritten after the snapshot is `rewritten`. A new sidecar after the snapshot (a forged dispatch) is `created`. Both are restorable.
4. NEW `tests/unit/worktree-conditions-provenance.test.cjs`, hermetic via `assert-harness.cjs`, with a fixture worktree whose default graph is `<wt>/.planning/graph`:
   - two `recordInflight` calls with the real `dispatch-record.cjs`, then `check('arch-review', …)` passes both times;
   - `recordPr` with the real `pr-ledger.cjs`, then `check` passes;
   - after a snapshot, a rewritten sidecar and a forged new sidecar are reported, and `restore` puts back the bytes and removes the forged file;
   - an unknown untracked file under `.planning/graph/` outside the host-owned entries still refuses `UNTRACKED_UNKNOWN`.
5. Comment policy on added lines.

## Out of scope

## Acceptance criteria

- Two in-flight recordings in one worktree never make a later `check` refuse.
- A role that rewrites or forges a provenance sidecar or the PR ledger is detected by `diffSnapshot` and undone by `restore`.
- The host-owned set is defined in exactly one place: `worktree-conditions.cjs`.
