## Goal

**Narrowed 2026-09-25:** release 0.62.1 (`21232273`, #221) already passes `-- . ':(exclude).planning'` to the integrator `combinedDiff` in `claude-role-host.cjs` and documents it in `references/integrator.md`. This ticket builds on that change and delivers only the remainder: exclude `.shipyard-role-artifacts/` as well, add the `.planning` name-status and blob-digest summary to the packet, and replace the raw `git preflight failed` dump (a `maxBuffer` overflow prints the diff) with a refusal that names the bound, the measured size and the measuring command. Do not re-implement the `.planning` exclusion.


ADR-018 decision 7 (D-48). The integrator judges the full code diff, excluding `.planning/` and `.shipyard-role-artifacts/`, plus a name-status and blob-digest summary of `.planning`. When a bound is still exceeded, it refuses with a named remedy and the command that measures the size.

Epic 39 measured 1,935,272 B in total. Of that, 1,465,974 B was `.planning`, which leaves 469,298 B of code, against the 1 MiB diff bound (INV-005 constraints B4, C-T1). A shared deterministic producer gives Codex the same input through `references/integrator.md`.

## Scope

1. NEW `plugins/delivery-pipeline/scripts/integrator-diff.cjs`:
   - `codeDiff({worktree, mergeBase, head, run})` runs `git diff --no-ext-diff --unified=50 <mergeBase>...<head> -- . ':(exclude).planning' ':(exclude).shipyard-role-artifacts'` with `maxBuffer` set to `maxBytes + 1`. `maxBytes` is passed by the caller: the role host passes its `DIFF_MAX_BYTES`, and the CLI uses the same 1048576 default. The module never imports the host. It returns `{content, bytes}`.
   - `planningSummary({worktree, mergeBase, head, run})` runs `git diff --no-ext-diff --no-renames --raw -z --full-index <mergeBase> <head> -- .planning`. It parses the output into entries `{status, path, old_mode, new_mode, old_blob, new_blob}` sorted by path. When `.planning` is absent from both trees it returns `[]`.
   - It exports `PATHSPEC_EXCLUDES = ['.planning', '.shipyard-role-artifacts']` and `measureCommand({worktree, mergeBase, head})`, which returns the shell-copyable measure command.
   - CLI: `--worktree <wt> --merge-base <sha> --head <sha> [--json]`. Unknown flags refuse. It uses argument arrays only.
2. `claude-role-host.cjs` `prepareIntegrator`:
   - `combined_diff.content = codeDiff(...).content`;
   - add `combined_diff.pathspec_excludes` and `planning_changes = planningSummary(...)` to `roleContext`.
   - Above `DIFF_MAX_BYTES`, refuse with the message `role diff exceeds the bounded context packet: <bytes> B > 1048576 B after excluding .planning and .shipyard-role-artifacts — measure: <measureCommand>; remedy: split the oversized code change across smaller tickets or phases and re-run the integrator`.
   - The prompt bound at `:637` gets the same measure and remedy. The other roles keep `diffText` unchanged.
3. `references/integrator.md` "Input": state that the combined diff excludes `.planning/` and `.shipyard-role-artifacts/`, that `.planning` arrives as a name-status plus blob-id summary, that the same input is produced by `node <plugin>/scripts/integrator-diff.cjs --worktree … --merge-base … --head … --json` on Codex, and that it works with tracked and untracked `.planning`. Keep `## Verification contract` unchanged.
4. NEW `tests/unit/integrator-diff.test.cjs` (hermetic fixture repository):
   - a large `.planning` change plus a small code change gives code-only content;
   - `.shipyard-role-artifacts/` hunks are absent;
   - the summary is sorted and carries full 40-hex blob ids;
   - untracked `.planning` gives an empty summary;
   - the CLI JSON shape.
5. `tests/unit/claude-role-host.test.cjs`:
   - the integrator fixture epic with more than 1 MiB of `.planning` and a small code diff prepares successfully, with `planning_changes` present;
   - a code diff above 1 MiB refuses, and the message contains the measure command and `remedy:`.
6. Comment policy on added lines.
