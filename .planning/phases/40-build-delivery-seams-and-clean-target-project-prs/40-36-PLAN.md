## Goal

ADR-018 decision 6, code half (D-52). At publication, executor artifacts are validated in a historical mode against their recorded base commit and tree, instead of the live base tip. So an epic move no longer makes a fresh artifact `STALE_ARTIFACT`. Historical mode is explicit, never automatic. It still binds the head, and it requires the recorded base to be an ancestor of HEAD. Freshness against the live epic stays with base-merge and the merge gates.

## Scope

1. `expectedManifest(input, …)`: when `input.historical === true`, drop `base_commit` and `base_tree` from the live-equality list, and instead require all of:
   - `gitObjectIdentity(input, worktree, manifest.base_commit)` resolves, and its tree equals `manifest.base_tree`;
   - `git merge-base --is-ancestor <manifest.base_commit> HEAD` succeeds;
   - `head`, `head_tree`, `base` (the name), repository, worktree, dispatch and policy stay live-equal.
   Any failure is `STALE_ARTIFACT`, with a message naming the failed binding and the remedy (re-dispatch the executor from the current base).
2. `validateExecutor` and `readExecutor` pass `historical` through, and return `historical: true` in the validated object when it was used.
3. There is no silent fallback: a non-historical validation that fails `STALE_ARTIFACT` never retries in historical mode.
4. `tests/unit/role-artifact.test.cjs` new cases:
   - a fresh executor artifact after the epic moves: non-historical gives `STALE_ARTIFACT`, historical is valid with `historical: true`;
   - historical with a recorded base that is not an ancestor of HEAD gives `STALE_ARTIFACT`;
   - historical with a tampered `base_tree` gives `STALE_ARTIFACT`;
   - a head change still fails in historical mode;
   - the CLI `validate --historical` and `read --historical` for executors.
5. Comment policy on added lines.

## Out of scope

## Acceptance criteria

- Executor validation is historical only when the caller asks for it.
- Historical mode binds the recorded base commit, its tree, ancestry to HEAD, and the live head and head tree.
- The repair and drift historical behaviour is unchanged. Their existing tests stay green.
