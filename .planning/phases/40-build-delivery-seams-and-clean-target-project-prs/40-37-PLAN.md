## Scope

1. Publication (steps 5d and 6):
   - executor `role-artifact.cjs validate` and `read` lines gain `--historical`;
   - one sentence states that historical mode binds the recorded base commit and tree plus the live head;
   - `gh pr create --base <state[T].base>` stays on the live base;
   - `base-merge.cjs` is named as the step that brings the PR current, including a sibling carry on a tree-object proof (REQ-151 behaviour is described only).
2. Pre-launch: name `bash <plugin>/scripts/ticket-worktree.sh verify <T> --role <role>` and `worktree-conditions.cjs` as the check every host runs, and state that refusals carry a copyable remedy and that out-of-scope role mutations are restored and reported.
3. Draft rule: arch-review runs on the draft PR. Undraft happens only after `conform`. The sentinel and the merge gate refuse drafts.
4. NEW `tests/unit/deliver-worktree-conditions-contract.test.cjs`. It asserts:
   - the executor `validate` and `read` lines contain `--historical`, and the PR create line uses the live base;
   - `ticket-worktree.sh verify` and `worktree-conditions.cjs` are named;
   - the draft rule sentence;
   - every `scripts/<name>` the new sentences name exists;
   - `ticket-worktree.sh` prints `verify` in its usage;
   - `role-artifact.cjs validate --help`, or a dry parse, accepts `--historical` for executors.
5. No code comments are involved.
