## Goal

One module, `planning-result-sealer.cjs`, produces both `shipyard.research-result.v1` and `shipyard.decomposition-result.v1` envelopes with a bounded artifact index (D-12). The Claude research path (`claude-delivery-host.cjs`) and the Claude decompose host both use it. The Codex hosts adopt it in T-40-11 and T-40-12. The sealer also exports the containment check that the Codex researcher hosts need (D-13): a worktree may contain changes only at the allowed artifact paths.

## Scope

- NEW `planning-result-sealer.cjs`:
  - `sealResearch({root, scope, lines, limits})` moves the body of `sealPlanningResearch` unchanged in behaviour. Each of the 11 conditions becomes its own refusal code and message naming the line and the file (for example `RESEARCH_LINE_MISSING`, `RESEARCH_ARTIFACT_SYMLINK`, `RESEARCH_SUMMARY_TOO_LONG`), instead of `planning research has invalid scope or result`.
  - `sealDecomposition({root, scope, plans, extra})` returns `{schema: 'shipyard.decomposition-result.v1', version: 1, scope, artifact_index: [fileReference…], plan_count}`, bounded by the same size caps and sorted by path.
  - `researchLineFailure({scope, sealed, failed: {line, code, cause}})` returns the frozen partial-failure shape `{status: 'blocked', failed_line, code, cause, sealed_lines: [...]}` that both research hosts return when some lines sealed and one did not (used by T-40-12 and T-40-13).
  - `assertContained({worktree, allowed})` runs `git status --porcelain=v1 -z` with argument arrays and refuses `CONTAINMENT_VIOLATION` listing every path outside `allowed`.
  - All envelopes are frozen objects.
- `claude-delivery-host.cjs`: `sealPlanningResearch` becomes a thin call into `sealResearch`, and its outputs stay byte-identical for valid input.
- `claude-decompose-host.cjs`: `runDecomposition` returns `sealDecomposition(...)` over the plans it produced.
- NEW `tests/unit/planning-result-sealer.test.cjs` (`os.tmpdir()`, hermetic git for `assertContained`):
  - research envelope equals the pre-extraction envelope for a fixture;
  - each refusal code fires for its condition;
  - the decomposition index lists every plan with correct sha256 and rejects symlinks and oversized files;
  - containment passes for the allowed path and refuses an extra file.
- `tests/unit/planning-artifacts.test.cjs`: switch assertions on the generic message to the specific codes.
- `tests/unit/claude-decompose-host.test.cjs`: the host result carries `shipyard.decomposition-result.v1` with an index.
