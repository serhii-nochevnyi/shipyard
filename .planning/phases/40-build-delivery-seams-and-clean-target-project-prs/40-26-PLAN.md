## Goal

The supported command surface names the new seams (D-02, D-06, D-09, D-10, D-16):

- `make capture-fixtures` (manual, scrubbed, records the CLI version);
- `make test-live` (one live round per runtime);
- `make release VERSION=x.y.z` (refuses without fresh live receipts);
- `make refresh-runtime-digests` (the only way to change the pin, plus the trailer);
- `make install-shipyard-dogfood-claude` / `make install-shipyard-dogfood-codex` (separate install root);
- `make untrack-planning` (dry run; apply needs `CONFIRM=untrack-planning`).

`README.md` and `CLAUDE.md` document them. `tests/smoke/docs-smoke.sh` stays green, because every make target the README names exists.

## Scope

- `Makefile`: add the targets above. They are not added to `test-fast` or `test`, because live, capture and release need credentials. Each target is a thin wrapper that forwards `RUNTIME`, `BOUNDARY`, `VERSION`, `DOGFOOD_ROOT`, `CONFIRM` variables and validates required variables early with a clear error. `test-live` runs `bash tests/live/live-round.sh --runtime claude` and then `--runtime codex`, stopping at the first failure. Add them to `.PHONY`.
- `README.md`: a "Release and live verification" section (`make test-live`, `make release`, receipt location and 7-day freshness); a "Boundary fixtures" section (`make capture-fixtures`, when to re-capture, scrubbing); a "Dogfooding unreleased hosts" section (separate root, provenance, doctor report, no default-branch merges); a "Planning files in target projects" note (`make untrack-planning`); and the digest refresh rule with the trailer name.
- `CLAUDE.md`: add the new targets to the test/command list, and add one editing rule: "Change the runtime-file digest pin only with `make refresh-runtime-digests` and the printed trailer."
- No comment lines in the Makefile beyond what the file's existing style uses.
