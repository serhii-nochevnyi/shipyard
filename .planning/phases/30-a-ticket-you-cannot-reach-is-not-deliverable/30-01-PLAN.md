## Goal
Make verification claims executable across delivery boundaries.

## Context (Reads)
ADR-010, the phase UAT/VERIFICATION projections, and the current delivery owners named below. Existing behavior is verified in the cited source before implementation; new helpers extend the existing lock/store and config patterns.
 The canonical delivery-rules skill, all seven role references, the three Workflow prompt builders, and source-contract.test.cjs. The existing source-contract test already sweeps wiring claims; extend that behavior instead of adding a second checker.

## Scope
Add the rule-zero contract that every checkable claim names its command, carry it into each role document and every prompt builder that bypasses role documents, and add the arch-review violation criterion. Extend the existing source-contract sweep to assert each required home and its caller. Keep generated Codex artifacts out of the write set; their generator/install smoke consumes the canonical sources.

## Out of scope
Changing tracker eligibility, model policy, or reviewer behavior; deleting user repositories or worktrees; credential repair; monorepo sub-path semantics; and unrelated historical planning repairs.

## Acceptance criteria
- Every required role reference and Workflow prompt builder states the command-backed verification rule.
- The arch-review contract reports an unverified claim as a violation and names the missing command.
- The source-contract sweep fails when any required home or caller is removed and passes on the complete set.
- No prompt builder or role reference gains a contradictory verification instruction.

## Test strategy
Use focused unit fixtures and negative cases first. Keep network, credentials, live trackers, and provider quota out of local verification; put proving-ground-only behavior in the integration evidence. Preserve the existing full CI gate for the phase.

## Verification commands
~~~bash
node --test tests/unit/source-contract.test.cjs
~~~

This is the cross-cutting REQ-84 ticket. It is a documentation and contract change and blocks no other plan.
