# Options — native ladder adoption

[Canonical comparison](research/alternatives.md) considers four materially distinct options at the verified source revision. The exact substitutions and expedited implementation intent were already selected by the user in [DECISIONS.md](DECISIONS.md); this synthesis records that intent, not a newly invented approval.

| Option | Tradeoff | Disposition |
|---|---|---|
| A — retain v6 and gather evidence | Lowest engineering cost; leaves requested defaults and floating Sonnet alias unchanged | Historical control; does not satisfy expedited adoption |
| B — one coherent versioned native fast slice | One reviewed policy/generation/install transition; more simultaneous tuple changes complicate attribution | Chosen direction under existing explicit adoption and expedited-delivery decision |
| C — multiple complete versioned stages | Cleaner identity/placement attribution; repeats reviews, generated bundles and installation boundaries | Valid later experimental structure; not required before building the authorized migration |
| D — redesign host and outer coordination together | Larger repeated-input opportunity but active owner collisions and confounded model/context effects | Outside native fast slice; existing phase43/45 owners retain this work |

B includes reachable exact native rungs, pinning, adapters, derived repair predecessors, generation/mirrors, negative/application fixtures, scoped docs and isolated install provenance. Two extra Claude executor failure-driven transitions are deferred until a trustworthy attempt/classification contract exists; base medium and critical/checkpoint xhigh are supported now. Outer D6 activation is deferred; revised Sol61/low and Sonnet55/xhigh candidates remain recorded. No gates, historical controls or receipt identity are weakened.

Gate 1 acceptance and production rollout remain explicit orchestrator gates. Implementation must verify live pairs and installed identity. Quality/economy remain unknown and are tracked separately in [RISKS.md](RISKS.md). Complete alternatives, dependencies, sources and uncertainties remain in the [sealed alternatives report](research/alternatives.md).
