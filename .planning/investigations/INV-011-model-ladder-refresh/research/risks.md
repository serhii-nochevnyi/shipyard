Deliver the smallest coherent native policy/adapters/config/generator/tests/docs change on an isolated graph, preserving Fable, sentinel and all gates. Run the proposed matrix and smoke suite on both runtimes; validate staged/installed artifact identity; then permit bounded host-owned application launches and inspect exact receipts.
